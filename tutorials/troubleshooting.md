# 故障排查、停止与恢复

| 现象 | 先核对什么 | 处理方向 |
| --- | --- | --- |
| 找不到主命令 | `.venv/bin/omi-shapeforge --help` 是否可用 | 使用显式路径或安装后的同一解释器，不混系统 pip |
| doctor 路径 false | `--config` 是否在子命令前、路径基准是否为配置目录 | 修改忽略的 local.toml，再只读检查 |
| doctor 全 true 但 GPU 失败 | 当前测试只验证文件路径 | 看后端 run.log；核对库、GPU 和模型，不能当成已验收 |
| 克隆后缺后端样例脚本 | 适配与入口仍可能未提交 | 恢复完整后端版本／补丁；只记差异哈希不能恢复代码 |
| 输出目录已存在 | 是否复用了历史 run | 选择新名字，不删除原证据来绕过保护 |
| 配准模型头尾不对但残差低 | ROI、方向候选及全部原始点统计 | 不能只用检查子集分数判定绝对位姿 |
| Blender 脚本缺 bpy | 是否交给普通 Python 运行 | 使用 Blender `--background --python` |
| 模型尺寸异常 | 照片稿是否仍未定标、坐标是否重复变换 | 使用米制版本；已变换 PLY 不再套同一矩阵 |
| MuJoCo EGL 失败 | 环境和本机 OpenGL／EGL 库 | 保留日志；headless 物理与渲染是不同检查 |
| MuJoCo framebuffer 太小 | XML 中 visual/global 的 offwidth/offheight | 使用当前生成器；旧失败场景可能缺 960×720 缓冲配置 |
| Isaac 扩展解析／启动超时 | 是否用本地 python.sh、本地扩展目录和受控启动脚本 | 使用当前入口；不随意打开在线注册表下载代替依赖核对 |
| Isaac 物体不动 | 是否仅写 USD、是否实际 attach stage 后步进 | 以当前 runner 和报告为准，不把静态导入当物理通过 |
| 缺机械臂或夹爪 | 相应 local 资源是否实际到达 | 按[资源清单](../manifests/README.md)恢复完整网格树；SDK／文档不等于几何 |
| HTML 空白或 GUI 不启动 | 浏览器 WebGL／本机显示服务 | 当前只验过数据与后台路径，不能声称交互已通过 |

新实验用新输出。Ctrl+C 后保留失败目录和日志；需要重跑时只引用已校验输入。不要复制旧机器 venv、整体覆盖配置、删除无关缓存或启动其他仓库的硬件控制脚本来排查本项目离线任务。
