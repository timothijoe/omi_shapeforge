## 数据与方法

真实像素来自已有6秒腕部视频的第0帧，使用原分辨率图像；不是外部手机拍摄夹爪的视频。前景采用既有人工提示SAM2指尖／内衬分割，加上手工外臂／底部掩码及橙色内衬边界修整，明确排除原画面中的模块、绿色拉手和背景。完全不透明的前景核心共149335像素，与源图逐像素相同；仅边界做轻微羽化。

渲染使用V4-r05「双窗尾槽版」及SIM-r06中的18.8 × 8.8 mm插槽，模块处于距孔口约2 mm的预插入显示位置。读取用户提供的`/home/linux/Downloads/img/wrist_intrinsics_1920x1080.json`（OpenCV fisheye K、D），将六个2048方形MuJoCo视图重投影到原鱼眼图域。关闭相机头灯并设IPD=0，避免立方体面之间的光照／视点接缝。

相机相对模块的位姿复用之前首帧图像配准的粗略先验，**不是新外参标定**。本图的视点配准独立于此前腕部工具外观候选的90°针孔镜头设置，没有静默修改该实时场景。

合成后仍可见8485个模拟模块像素和33148个模拟插槽像素。完整图保留1920×1080坐标域；展示图是`(600,510)～(1350,1060)`区域等比例放大至1200×880。原场景XML及其网格哈希检查未变。
