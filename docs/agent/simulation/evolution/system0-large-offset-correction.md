## 误差与展示定义

`pose_correction.py`由实际TCP和固定夹爪中心变换计算当前夹爪位姿。沿真实插接轴扣除前进分量，在目标夹爪Y／Z方向报告有符号横向／上下误差；以目标夹爪朝向为基准提取ZYX欧拉俯仰／偏航。这样沿插入轴前进不会被误算为横偏。原任务中的模块中心横向误差、接触与成功判据仍单独保留，展示指标不参与控制或终止。

`summarize_pose_correction.py`保存全10 Hz原始状态计算出的CSV、JSON和逐条件曲线，模型及来源核验与统计均可复算。相关31项测试通过；轻量101项中29通过、72跳过，两个实际worker完整退出0。

四个完整demo保留有／无路径对照：正、反组合用清晰腕图和外部近景；单独横移、偏航用外部主视图。实际图像按每两步采样（5 Hz），原速播放时保持前一帧，不插值制造运动；原10 Hz状态完整保留。全部偏差值逐点复算，采样状态、相机及完整视频解码核验通过。

另有20.6秒短片：左右均为同一个有路径模型、两种相反初态，仅截取开始15秒，并非完整插入，也不是左右有／无路径比较。青线是实际走过的夹爪中心轨迹，RGB是该中心的当前朝向，非System1参考路径。

用户随后反馈没看懂。已解释上述左右含义，并新增单个模型、单个正向组合初态的68秒完整演示：左为外部视角，右为同一次动作的腕部图像，取消轨迹／坐标箭头，只保留三个偏差与“起点→调整接近→实际入孔→完成”标记。阶段按真实尖端深度越过孔口的第333步切换，任务完成仍取原第624步success；较早v1使用entry-qualified第360步切换，已另存修订版，避免将入孔后的最初一段标成孔外。新版本是展示说明，不重放物理、不改变策略数据。
