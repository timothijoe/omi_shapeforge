# 快速5子步配置的规则插入精度回归

2026-11-24，用户在RL五回合速度对照后要求优先确认：同样的rule-based方法，在提速后的环境里是否仍能精确插入。本阶段不训练或调整策略，也不修改控制器、任务阈值、几何、摩擦或驱动参数。

## 当前确认与接续边界

用户在查看结果后要求保存当前进展。本阶段确认：现有快速5子步环境仍能由原规则完成插入；本轮与20子步对照均5/5成功，5子步最大终点横向误差约0.059 mm、角度约0.0059°、深度误差小于0.001 mm。判据未放宽，结论限于当前固定模型和所列扰动，不能据此宣称所有接触过程或真实力精度等价。

速度结论与策略能力分开保存：同一冻结RL Actor新旧各5回合，墙钟462.170→32.644秒，整体约14.16倍、按控制周期约13.50倍；两组自主成功率均0/5，全部入口资格失败。规则能插入说明快速环境并未失去完成该任务的能力，但不能据此确定RL失败的唯一原因。详细速度口径见[吞吐总账](isaac-control-throughput.md)，学习问题仍见[多样化示范](diverse-demonstrations.md)。

建议的快速实验配置仍是CPU物理＋原厂IK＋5子步＋双渲染子帧＋异步记录，需显式启用；裸worker／批量入口默认值未切换。本次记录不再启动实验、不重训BC／RL、不修改代码或阈值。后续若继续学习诊断，应沿用明确的执行合同，分别保留规则成功与纯策略失败证据。

## 比较设计与同源核对

复核已有500子步DLS、原厂IK＋20子步、原厂IK＋5子步的正常91000／±1 mm恢复91001、91002三组带RGB轨迹。三组`contact_teacher.py`、`isaac_recovery.py`与`insertion_task.py`哈希完全相同，恢复配置、严格入口指导和成功／失败判据相同；旧500子步结果直接复用完整原始证据，没有重新挑选案例。

再运行20和5子步各5例：正常91000；TCP横向+0.6 mm与绕插槽X轴+0.5°组合偏移93001；TCP高度−0.6 mm与绕插槽Z轴−0.5°组合偏移93002；±1 mm受阻恢复93003、93004。每例只有一次reset，准备偏移通过正常控制动作完成，不传送机器人或修改任务目标；姿态准备须达到目标角度误差0.00025 rad以内后才交给原规则。姿态偏移实际约0.487～0.492°，结合TCP偏移后模块中心横向偏差约2.11 mm。

新增测试只运行真实PhysX与规则控制，不渲染训练图像。正常91000分别与已有20／5子步带RGB轨迹做桥接：步数388／358相同，逐步关节目标、关节实测、TCP、深度、横向／角度、重叠及穿透数据差全部为0。这项核对支持用该物理诊断检查几何精度，不将无图像数据冒充视觉训练数据。

## 判定与独立检查

成功回合全部具有入口资格、最终肩部接触、连续3个落座稳定采样，未触发失败判据。入口资格审计按原合同检查：在1～5 mm窗口内连续积累合格对准采样，然后跨过5 mm时切换为已获资格；这10例窗口内实际有21～24个连续合格采样，超过要求的3个。没有把首次资格切换时刻必须仍位于5 mm以内作为额外错误条件。审计脚本对此边界的初始误读与修正单独保存，未改动任务实现或轨迹。

两种偏移恢复均确认实际受阻和至少一次完整退出／重对准／重插。姿态准备的实际角度与位置也有记录。最终实测关节通过独立NumPy FK回代，与USD TCP的位置差最大约0.000275／0.000313 mm（20／5子步），旋转差通过原导入一致性阈值。所有10个新增回合的连续步号、固定任务目标和相应入口／稳定落座条件均核对通过；两个worker及client／shutdown全部退出0。

## 与原500子步的历史精度关系

在已有相同三个种子的带RGB参考中，旧DLS＋500子步为3/3，最大终点横向误差0.052429 mm、角度0.004334°、深度误差0.000595 mm；原厂20子步为3/3、最大横向0.047568 mm；原厂5子步为3/3、最大横向0.059390 mm。快速配方在这些案例中仍保持同量级终点精度，但这不是所有物理轨迹或接触力都等价的证明。

结论：当前证据支持规则控制器在快速5子步配置中仍能完成入口对准、受阻恢复及精确落座。此前RL新旧均0/5不能简单解释成“快速环境已经无法插入”；规则成功也不能代替学习策略验证或排除观察／执行配方迁移对策略的影响。尚未验证更大扰动、任意插槽、真实夹持、瞬态力精度或真机。
