# 固定WG-r09后的位姿与其他因素试验

2026-11-22，用户认可点云版后，要求继续检查是否还有位姿问题及其他可能。已固定r09全部mesh，完成六组独立试验及实际鱼眼渲染。结论：**镜头还有小幅调整空间，但不能统一解决剩余差异；模块逐样本相对位姿和绿色拉环结构是明确的后续方向。r09主版本与已有内参文件保持不变，未采用任何诊断参数替换。**

## 试验方法

从r09当前可见轮廓向内2像素发射射线，取得20个黑臂／黄色外缘局部3D样本，加上既有六个指尖角点与掌部边界。先以固定局部对应作小范围参数拟合，再用真实MuJoCo渲染复核，不能只采用优化器的误差。

使用unit001开发帧拟合，复核003／008／012／014。真实外缘仍是局部颜色连通区域估计，不是精标；选定特征沿用此前人工审阅的角点、被遮挡点剔除规则及掌部垂直边界误差。保持场景几何、光照与裁剪一致，测试相机位姿、对称开度、小幅焦距倍率，以及假设铰点下的拉臂±40°旋转。未重新优化畸变系数，未叠加真实夹爪像素。

## 模块相对夹爪位姿确有样本差异

检查4个单元可见的金属尾缘，其图像行位置约为762、744、783、785 px，跨度约41 px；而夹爪固定特征基本稳定。说明模块相对夹爪的平移／倾角不能在整批数据中一概固定。这里只做约±3 px人工边界判断，没有把印刷marker内容当作特征。

自动模板跟踪得分低、对应错误，已拒绝使用，没有将其输出包装为6D标签。固定其余参数、只改变模块轴向位置，可以用约+5.0、+15.3、−5.8、−6.7 mm解释各尾缘行位置，但这只是**非唯一的一维解释**，不能区分平移、倾角和其他几何误差，也未作为真实抓取位姿采用。

## 绿色拉环存在具体几何遗漏

重新读当前光模块mesh后确认，两份绿色拉臂几何分别位于模块X负侧和正侧，中间最近距离约13.42 mm，没有跨两侧的U形连接段；实物照片明显具有该连接结构。内部网格有分块，不能用原始未焊接的面连通计数来判断拉环闭合；这里依据的是实际跨侧几何缺失和两侧包络。

保持mesh形状不变，将两侧拉臂绕假设铰点上下旋转40°，绿色可见像素由约138变为421／299，但仍未复现实物U形轮廓。转角／铰点是诊断假设，未作为正式可动机构。**缺失的连接几何不能靠整体相机位姿补出来。**

## 当前结论与下一步优先级

1. 单独补全绿色U形连接结构，并区分拉环本身的转动／弯曲与模块刚体位姿。
2. 用可见模块几何边缘建立逐样本的模块—夹爪位姿候选，结合多视角／时序约束；不能用一个固定变换覆盖全部采集。
3. 镜头仅在已有内参固定下做小范围联合复核。当前微调候选存在指标权衡，先保留，不把它当最终标定。
4. 黄色衬垫还可能有局部形变、遮挡及光照差异；本轮没有证据把所有黄色轮廓误差归为开度或焦距。
