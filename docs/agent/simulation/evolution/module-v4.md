## 与视觉特征提取的关系

上侧缺口提供额外轮廓转折和两处内角，侧片缺口与尾端凹面提供局部边缘及遮挡关系，理论上可减少长方体平面带来的匹配歧义。但尚未将V4接入真实图像位姿算法，也没有与旧模型做定位误差或跟踪成功率对照，**不能据此宣称视觉策略已经改善**。

后续应在视频中标定这几处结构的可见帧、2D边缘与相应3D点／线，先检查重投影和遮挡一致性，再做相同帧集的V3／V4对照。金属高光不是稳定几何边缘；槽尺寸误差也会引入错误的投影约束。训练、碰撞代理及插入验收尚未切换到V4。
