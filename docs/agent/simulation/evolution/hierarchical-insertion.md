# System1 与 System0 独立插接原型

2026-11-25，按用户要求新增独立实验链路：System1支持真值、位姿偏差／抖动／延迟以及可训练视觉估计；System0接收路径与实际运动反馈，直接输出六维增量，自行决定推进和倒退。随后按用户补充，第一版使用虚拟腕部六维力／力矩，不使用双指触觉。

[运行教程](../../../../tutorials/hierarchical_insertion.md) · [讨论背景](../../../design/system1-system0-path-conditioned-rl-discussion.md) · [验证清单](../../../../manifests/hierarchical_insertion_20261125.json)

## 实现与隔离

新学习代码位于同级 `omi_proj/src/omi_hil_rl/training/hierarchical_insertion/`：

- `reference.py`：真值／噪声／学习型System1、坐标变换、因果延迟队列、局部路径预览。
- `environment.py`：独立Gym适配，直接动作、运动与腕力历史；保留原worker任务奖励。
- `system1.py`：双RGB小型CNN，监督预测TCP相对插座位姿，再由几何解码器生成路径。
- `cli.py`：`collect`、`train-s0`、`evaluate`、`train-s1`，检查点、经验池、独立回合划分和审计。

ShapeForge新增 `scripts/simulation/run_hierarchical_insertion.py` 编排worker及单项实验。旧 `hil/networks.py`、旧训练入口、旧经验池格式和默认观测均未修改。新增System0使用独立SB3 SAC及 `omi-hierarchical-insertion-v1` 合同，旧Actor不能直接作为新模型加载。

现有 `isaac_rl_worker.py`只增加显式可选的 `--wrist-wrench`及测量原点配置；默认不开启，新增字段只出现在开启该选项的执行合同与诊断info中，旧策略RGB/state/tactile张量布局不变。新增观测器只累计接触报告，不发控制指令。新launcher默认显式开启腕力。

## 上下层接口

System1提供平滑旋转的入口接近参考及轴向路径。默认每5个控制周期更新、8点预览、点距0.5 mm；可以按回合施加平移／转角偏置，按更新施加抖动，并延迟交付。当前是仿真步驱动的异步建模，不是已经部署的ROS topic节点。

System0输入为：TCP坐标系下的路径预览、最终几何目标、可回退的投影进度、参考年龄和有效位，以及最近4步的实际位移／旋转、上一完整动作和腕力／力矩／有效位。它没有额外的真实孔位、入口资格、恢复提示或GT接触阶段输入。GT／噪声模式可使用仿真位姿生成System1参考；learned模式只向预测器传图像与测量TCP，标签不进策略。

奖励与成功判据继续使用仿真真值，与噪声路径独立。模型评估禁止teacher查询，记录实际后退步数；System1不切换退回状态。规则老师只在显式采集示范时使用，来源标为scripted。

## 腕部传感器假设

仿真将模块外界接触冲量按符号求和，并用接触点相对测量原点的力臂计算力矩，按100 ms控制区间求平均。Fx/Fy/Fz单位N，Tx/Ty/Tz单位Nm；轴向随TCP，原点默认TCP，可用TCP系偏移配置到指定虚拟安装位置。

这是理想重力／惯性补偿后的外部接触wrench近似；不模拟完整腕部载荷、工具其他部位碰撞、电子噪声、零漂或硬件标定。固定夹持假设被显式检查，自由模块场景暂拒绝，不能据此宣称滑移鲁棒性。旧接触冲量模长统计继续只用于原任务评估，不能混称为新六维力。

测试覆盖接触对调换符号、力矩原点变换、旋转坐标及相反力的合力／力偶。实际三条规则采集中1077个动作、10个非零wrench区间；世界+X推进时，轴向接触力最小约−0.38635 N、最大0，合力模长未超过原接触冲量模长和。该检查验证信号方向与合成一致性，不是真机力标定。

## 当前验证范围

规则采集使用已有WG-r10／OM-r08分阶段固定夹持资产，5物理子步、天机IK、插槽平面±0.2 mm及偏航±0.1°随机化，max_steps=650。采集种子121000～121002，2训练＋1验证，三条均成功；成功来源为规则老师。

System0冒烟执行BC200次更新、40个SAC交互步，learning_starts=8，batch16。保存模型与经验池后独立重载，使用同一留出种子123000对照GT／噪声／learned参考。短预算用于检查实际执行链路，不能解释为已收敛的插接策略。

System1在三回合图像标签上独立训练3轮，按回合留出验证；验证TCP相对插座平移均值约11.913 mm，旋转均值约0.0985°，无退化旋转预测。该精度不足以证明可用的入口定位，也不是现有ResNet-18感知模型的成绩。

评估和默认兼容对照的实际结果、原生退出码、单元检查统计以[验证清单](../../../../manifests/hierarchical_insertion_20261125.json)为准。所有输出使用独立运行目录，未覆盖历史资产、数据和检查点。

同一System0权重、留出种子123000的结果：GT为0/1（650步超时），噪声参考为0/1（650步超时），learned为0/1（376步入口资格失败）；三者teacher请求均为0。这只完成了独立重载与参考切换验证，没有学会可靠插入或恢复；实际负向运动步数也不能当作有目的的恢复成功。

被动传感器兼容对照复用种子121000／121001：开启和关闭腕力选项均规则2/2通过，720步执行动作、TCP位置／姿态、关节位置、插入深度、原接触指标及奖励项逐值差为0。轻量unittest共95项，29通过／66跳过；训练环境下同套检查67通过／28跳过。学习侧既有相关回归52通过／1跳过，新层级测试另行覆盖几何、延迟、真值隔离、动作与种子序列。

## 后续工作

1. 增加入口偏移、受阻、倒退调整重插的分层示范；现有三条正常示范不足以训练恢复。
2. 先在GT参考下形成可靠System0，再固定模型按同一留出种子扫描偏置、抖动、延迟和失效窗口；不要直接扩大到任意实仿接触泛化。
3. 扩展System1的几何／相机覆盖，必要时接已有ResNet-18位姿模型；保留独立测试集及尾部误差指标。
4. 配置真实腕力传感器安装原点、轴向、补偿、噪声和延迟合同，再设计真机适配；本原型没有硬件动作通道。
5. 对路径过期、突变与低置信度建立正式执行约束；目前只提供年龄／有效位和畸形输入拒绝，不能当作完整部署保护。
