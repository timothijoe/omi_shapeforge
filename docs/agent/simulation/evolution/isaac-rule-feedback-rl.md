## 场景和进程

输入为[右臂停放版](right-arm-park-and-hil.md)的固定WG-r10＋OM-r08传递包，原资产和以前的实验保留。当前组合首先实际完成规则插入218步、退出186步，采用gentle目标与10 N控制采样门控；结果在本轮`current_asset_rule_check/`。这是新组合的限定接触试验，不认证工具惯量、真实抓取或整机自碰撞。

Isaac 5.1独立进程负责PhysX、RGB与任务状态；`omi_sim_train`进程负责OMI现有视觉Actor、SAC、经验池和权重。两进程通过本机权限0600的Unix socket通信，消息为长度封装的JSON/NumPy，禁用pickle读取，不监听网络端口。训练没有调用ROS或硬件控制接口。

新入口：`scripts/simulation/isaac_rl_worker.py`；客户端在`omi_proj/src/omi_hil_rl/training/isaac_client.py`；完整试验入口为`omi_hil_rl.training.isaac_rule_feedback`。这不是把MuJoCo接口改名为Isaac，运动只由PhysX推进。

## 观测和动作合同

- 头部RGB实际渲染256×256，再下采样128×128。
- 腕部保持固定K/D和1920×1080像素域，使用`[566:955,766:1155]`的389×389 ROI，按`rint(linspace(0,388,128))`取样。所有该ROI射线落在90°前向立方体面内，因此每步用512×512前向渲染进行鱼眼射线采样，无须为未输入策略的区域渲染其余五面。
- 两路均为10×3×128×128因果历史；camera/history mask保留，state/tactile为零padding。仿真真值只供规则、奖励和评估，不进Actor或Critic的输入。
- 6维世界系TCP增量，经独立DLS IK和关节位置驱动；非操作右臂和夹指目标固定为该回合初始值。每个控制步推进0.1秒仿真时间、500个0.2 ms物理步；不承诺墙钟实时10 Hz。
- reset同时清空历史、任务阶段/保持计数、机器人及触点速度/状态。回合内只有动作驱动；模型不通过瞬移到位。

奖励沿用终止奖励＋势能差：势能为`−10×TCP距离(m)−0.5×角度(rad)`，折扣0.995、步长成本0.001。成功、物理保护、10 N采样门控和时间截断分别记录；失败优先于几何成功，截断保留bootstrap。

规则动作临近台阶采用gentle限速和0.03 mm目标余量。策略独立评估不调用规则、不使用该限速器；接口检查执行动作等于策略输出，`teacher_requests=0`。因此规则到位与自主到位不能混为同一结果。

## 学习与证据边界

两个训练示范种子500/501共441条，独立验证种子520共220条，均真实采集成功。初始BC用1000次策略头更新，视觉编码器冻结；验证选中第700步。屏蔽任一路图像都会改变编码特征与输出动作，说明两路图确实进入网络，不代表感知准确率。

小规模协议预先登记：2段训练示范＋1段验证示范，32次Critic预热、每在线回合64次SAC更新；先2回合，再独立进程从检查点续训1回合。评估种子700/701与示范、在线采集分开。BC无接管基线已完成0/2（一次侵入保护、一次力门控）。最终结果见下节及[本轮登记](../../../../manifests/isaac_rule_feedback_20261122.json)，没有用无接管表现改选测试集。

数据持续标为`scripted_demo`或`scripted_intervention`；用户接受规则作为反馈来源，不意味着伪造真人操作标签。MuJoCo合同保持兼容，Isaac规则来源需显式新合同才能写入对应数据集/经验池，旧replay与权重没有直接混入。

运行根：`/data/omi_runtime/runs/isaac_rl_20261122/`。包含worker源码快照、观测合同、分阶段源码、逐步执行审计、单帧数据、经验池、BC/SAC权重和阶段退出码。首个采集启动因frames父目录缺失失败，已修复，失败目录保留，没有计入示范。

本轮验证目标是软件闭环，小样本/冻结编码器不保证自主策略收敛；固定附着、等效触点、未标定鱼眼及填零传感器仍是模型假设。接触峰值和真实设备风险不能由仿真训练通过替代。

## 本轮最终结果

完整软件链路已经实际运行：规则示范→BC→带规则反馈的SAC→权重回用于新回合→独立进程续训→关闭接管评估。五个受监督阶段子进程（BC、BC评估、RL、续训、RL评估）均退出0；Isaac收到shutdown后清理并退出0。
