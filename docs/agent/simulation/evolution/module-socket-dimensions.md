# 光模块与插口mesh版本、尺寸速查（2026-11-23）

> 本机迁移提示（2026-11-24）：运行资源实体已迁至 `/data/shapeforge/runtime`；本文中的 `/data/omi_runtime` 是保留的兼容入口，指向同一份内容。目录映射与恢复要求见[当前资源契约](../../interfaces/local-resources.md)。

当前WVA-01及GC-r01使用**光模块V4-r08**与**SIM-r06插槽几何**；单独插槽展示资产为**OS-001/M1888-r01**。GC-r01没有改光模块或插口mesh。WVA、GC是组合／接触场景版本，不是新的光模块版本。

单位均为mm。光模块整体尺寸以下写成**轴向总长×横向总宽×总高（Y×X×Z）**，包括尾部和模型中已有拉环；插入截面是另一项。用户所测18.1×8.2是插入部分的横向宽度×高度，不是模块沿插入方向的总长度。

MEASURED-r01及V4各版均保留**插入截面18.1×8.2**（宽度含侧弹片），前端下唇处高度**8.0**。完整模型的18.71／19.10宽度包含拉环，10.81总高度包含尾部凸起，不能拿它们直接与18.8×8.8孔口作全长匹配。金属主体轴向长度约70.19，为沿用的建模估计，并非本次实测。

V4-r08的拉环角会改变整体外包围盒：中性姿态为上表数值；当前组合使用−35°拉环角时，模块局部轴向包围盒约**105.23×19.10×29.49**。这不代表主体变厚，而是拉环转出了主体平面。

原型与工作快照另保留`r01_prevalidation_001`、`r04_preview_before_window_correction`，不另计为正式新修订。旧V1／V2／V2.1为迁移包的独立mesh；PHOTO／METRIC／V3是后续Blender路线，不能仅按数字认为几何完全同源。

## 插口版本

这里“孔口”统一指金属基本通道净宽×净高；白色外框孔宽另列，不能混用。

| 版本 | 主要区别／状态 | 金属通道宽×高 | 白色外框孔宽 |
| --- | --- | --- | --- |
| OS-001/r01 | 端面清理，保留背后凸出结构 | 20.90×9.60 | 22.50 |
| OS-001/r02 | 后部削平候选，用户后来未采用 | 20.90×9.60 | 22.50 |
| OS-001/r03 | 收窄通道的早期候选 | 18.60×9.60 | 20.20 |
| OS-001/r04 | 在r03基础上略放宽 | 19.00×9.60 | 20.60 |
| **OS-001/M1888-r01（当前组合来源）** | 按用户测量修正孔口，并采用左侧6.9偏置 | **18.80×8.80** | 不以旧外框孔宽代替金属净孔 |

M1888-r01从SIM-r06派生，两者不是两套不同孔口尺寸。左侧内壁到白色外框对应外缘约**6.9**，测量口径暂按正面+Y朝−Y看、模型+X侧理解；不包括PCB或底座。

当前插口主要部件的模型尺寸：白色框架包围盒约**62.00×67.80×17.00**，PCB约**89.00×85.00×1.60**；整个装配含下方倾斜支架，在当前场景XYZ轴上的包围盒约**115.10×113.62×147.58**。这些是模型几何，不是用户测得的孔口尺寸或已认证的实物尺寸。

旧r01～r04完整GLB均保留底座，GLB采用Y-up，轴向包围盒为110.00×146.79×106.00；按宽×深×高阅读为110.00×106.00×146.79。部分Blender文件默认隐藏支架，且场景存在整体位姿，因此直接读取“当前可见对象世界包围盒”会得到另一组数字。不能把该差异误判为孔口或底座缩放。

## 碰撞仿真派生版本

另有SIM-OM001-OS001-r01～r06，它们是模块／插口／碰撞代理组合，而不是新增的独立产品mesh版本：

- SIM-r01／r02／r03：旧通道19.0×9.6，旧模块路线；r03为旧接触实验基线。
- SIM-r04／r05／r06：新通道18.8×8.8、V4-r05主体；r04／r05保留失败与代理修正阶段，r06为后续采用的代理修正版。
- 当前视觉组合把模块外观切到V4-r08，插槽来源仍是SIM-r06。GC-r01仅验证夹持，插槽碰撞在该单测关闭。

18.8×8.8孔口与18.1×8.2插入截面之差，是名义总间隙0.7／0.6，居中时单侧0.35／0.30。**并非全插入深度均有此间隙**：SIM-r06后方既有支撑使局部净高降到约8.296，局部单侧名义竖向间隙约0.048。细节见[实测尺寸接触记录](measured-v4-simulation.md)。
