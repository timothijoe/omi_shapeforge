## 模型与原资产的关系

`SIM-SMOOTH-GUIDE-candidate-r04` 是独立碰撞假设，不是实物力学标定；r01～r03保留。仍从WG-r10＋OM-r08、右臂水平停放的冻结transfer派生，没有自动切换到另一个视觉版本。原始mesh、材质、相机和旧训练记录保留。

旧r06碰撞代理中的内部支撑把竖直单侧名义间隙缩到约0.048 mm；7个等效触点的行程为0.15 mm。旧RL两次失败终态都有一个触点达到约0.15002 mm；这提示限位可能参与卡滞，但没有证明完整因果。旧BC在20.69→21.00 mm附近出现0.059→51.47 N的控制采样跳变，也没有据此确认具体阻挡零件。

最初r01～r03用6个解析凸网格替代模块、插座和等效触点的旧接触代理：一个18.1×8.2 mm轴身包络、一个肩部止挡、四个连续导向壁。名义通道18.8×8.8 mm，入口径向0.2 mm／轴向0.4 mm导入，模块尖端径向0.2 mm／轴向0.3 mm倒角。后续r04改为六个原生盒碰撞体及平直入口，不保留这些未测倒角，见文末。几何包络是工程假设。摩擦仍为0.2，没有通过整体降低摩擦或提高10 N阈值获得通过。

去除未标定内部支撑的接触代理后，目标中心从旧z=0.552083 mm移到通道中心z=0.3 mm；机器人预插入／到位TCP目标相应平移约−0.252083 mm。局部试验的模块起始位姿同样居中。外观网格数据不变，原等效触点body保留但不参与候选接触；候选尚不模拟电连接器弹片、锁扣和真实夹持。

全部新碰撞体从开始到结束保持启用，没有按深度关闭碰撞、瞬移到位或以重置替代退回。肩部止挡通过显式`contact_shoulder_pair`识别；历史模型默认保持旧识别规则。

## 诊断口径

历史`contact_force_N`为最后物理子步各接触点冲量模长除以dt后求和，不是轴向净插入力或腕部六维力。新诊断另外记录每个0.1 s控制区间的该指标均值、轴向投影绝对值之和的均值／峰值及各碰撞部件对的贡献。轴向投影取绝对值后求和仍不是净合力，不能与实测腕力等同。

机器人恢复探针使用正常IK和PhysX驱动依次完成：入口外横偏→向入口轻推至受阻→维持横偏退回→入口外对准→插入→退出。只在开头reset一次，阶段转换仅切换控制目标和终止计数，不更改物理位置／速度。它是脚本诊断，不是BC／RL成绩。

生成候选：在仓库根用`/data/omi_runtime/envs/omi_mesh_audit/bin/python scripts/simulation/build_smooth_contact_candidate.py --source <原transfer目录> --output <新的候选目录>`。局部源是`/data/omi_runtime/runs/isaac_contact_development_20261122/local_transfer`，机器人源是`/data/omi_runtime/runs/right_arm_park_20261122/transfer`。

局部验证使用`/data/isaac-sim-5.1.0/python.sh scripts/simulation/run_isaac_contact.py --transfer <候选local_transfer> --output <新输出目录> --steps 180`；反例分别增加`--lateral-mm 1`、`--lateral-mm -1`、`--yaw-deg 2`，半步长增加`--dt .0001`。

机器人恢复使用`/data/isaac-sim-5.1.0/python.sh scripts/simulation/probe_smooth_contact.py --transfer <候选robot_transfer> --output <新输出目录> --offset-mm 1`；另测`--offset-mm -1`及`--offset-mm 0 --dt .0001`。

验收要求入口偏差确实受阻、退回纠偏后可以重插、对准后5 mm至到位前1 mm连续推进，控制区间平均轴向绝对接触指标<1 N，同时保留10 N采样终止阈值和0.05 mm穿透阈值。1 N是本轮行为筛查条件，非实测插入力标准。电接触／锁扣、真实柔顺和任意初态鲁棒性不在此次验收内。

候选尚未成为已训练策略的环境；[旧BC／RL结果](isaac-rule-feedback-rl.md)仍属于原碰撞合同，不能混算。

### 接触检测参数复核

第一轮沿用旧模型每形状0.1 µm的contact offset。局部正常、±1 mm横偏、+2°倾斜和半步长共5项通过，六个新凸体的实际烘焙支持平面误差为浮点误差量级。机器人±1 mm都完成实际受阻、退回、纠偏并重新推进到约51.2805 mm；但当时限定上沿的接触判据没有连续通过三个控制采样时刻，故这两轮保留为超时失败，不算成功。后续事件检查见下文。

后续`contact5um/`单独复验每形状5 µm的contact offset，rest offset仍为0。新通道单侧0.3／0.35 mm的名义间隙允许这一级预测接触距离；旧复杂代理中约2 µm的局部缝隙约束不直接套用到新模型。变更的是接触生成参数，没有扩大成功位置／姿态阈值或10 N控制采样门槛。复现本轮时，局部和机器人探针命令均加`--contact-offset .000005`；其他环境入口若仍硬编码0.1 µm，不代表已使用本轮参数。

**后续事件证据修正了“只是接触丢失”的初步解释。** `contact5um/robot_aligned_smoke_r02`到位后每个控制步末尾仍有`CONTACT_PERSIST`：肩部持续接触下沿和右侧沿，但没有上沿接触。r01的止挡识别误限于上沿，导致真实接触被判为未到位。r02将肩部与四条口沿中的任一条接触识别为止挡；仍要求最后物理子步有接触、连续三个控制时刻稳定，位置／姿态及10 N阈值不变，不改为“区间曾接触即可成功”。

r02输出位于运行根的`r02/`，其local／robot transfer从原冻结包重新派生，六个几何代理与r01相同，止挡身份合同改变。新增回归检查覆盖四条口沿、拒绝轴身碰壁误报到位、历史止挡名称／末子步语义，以及接触监视器在第一子步前收到事件时的初始化。末端瞬移专项只用于定位事件问题，不能计入全程恢复验收；最终矩阵必须重新从预插入位置执行。

前两个探针开发失败也保留：第一份把成功到达入口外位置后的阶段结束当作异常；第二份只用较高的力阈值识别受阻，轻推已经停住却没有触发退出。最终探针使用“有接触＋连续六个控制步推进范围<0.005 mm＋目标仍在前方”识别这种低力受阻，然后真正退回；阶段切换不重置物理状态。

### 5 µm方案未采用，恢复0.1 µm并复核末端步幅

`r02/`的5 µm参数虽通过局部检查，但机器人入口出现约0.0603 mm瞬时穿透，超过0.05 mm阈值。将试探动作减半后仍出现，因而不能简单归因于靠近速度；这些回合均失败，未允许带着保护失败继续凑出成功。原0.1 µm两侧入口的最大侵入分别约0.00086／0.00212 mm。

另一个半步长试验在距肩部约0.0503 mm处停滞，既没有力也没有碰撞事件。后续配方写入`r03/protocol.json`：仍用r02几何和四条口沿识别，恢复0.1 µm contact offset；末段最小轴向**目标**增量从0.01 mm改为0.05 mm、到位目标余量从0.03 mm改为0.1 mm。它改变关节驱动目标，不瞬移实际模块、不允许穿透；保持原位置／姿态判定、三次末子步接触、10 N采样及0.05 mm穿透门槛。小目标在小物理步长下数值响应不足是诊断假设，最终以完整动态复验为准。

`r03/`的局部和机器人复现命令使用`--contact-offset .0000001`；上文5 µm命令仅用于复现未采用的对照。探针的入口试探上限为0.05归一化动作，故意偏移的接近过程较慢；这不是训练策略速度指标。

### 按碰撞部件固定设置检测距离

`r03/`恢复0.1 µm后，两侧入口侵入降至约0.00064／0.00109 mm，均完成真实退回、纠偏和重新插入。但在约51.279 mm处，肩部接触在控制区间内出现、最后子步报告为空，仍不满足三次稳定到位；因此这两轮也保留为失败，不能仅因深度接近就判成功。

`r04/`测试资产`SIM-SMOOTH-GUIDE-candidate-r03`：轴身和四壁保持0.1 µm，每个回合开始前只把肩部止挡碰撞体设为5 µm。该属性存在transfer geom的`contact_offset_m`中，由USD作者显式应用并写入`scene_manifest.json`的`per_collider_contact_offsets_m`；旧传递包没有该字段时完全沿用原全局值。各碰撞体和参数全程固定，无按深度切换、禁用或缩小几何。此方案同时验证入口和末端，而不是把全局5 µm的失败当作已解决。

最终验收须读取对应目录的实际报告；各轮输出以及原BC／RL成绩都保留，不能跨配方拼出一个成功回合。

### 原生盒几何对照（资产r04，运行目录r05）

`r04/`的肩部凸网格虽然取得了末子步接触报告，但初次到位接触又出现约0.0653 mm的穿透，仍按原门槛判失败。随后`r05/`用六个原生USD Cube／PhysX盒形状替代六个凸网格，保持轴身、通道和肩部名义尺寸；入口改为明确的平直口沿，不假设未测倒角。四壁连续、全部碰撞始终开启，原视觉网格保持不变。

本轮仍用轴身／四壁0.1 µm、肩部5 µm的固定检测距离和相同的有界末段控制，目的是单独检查碰撞表示的影响；没有放宽成功、力或穿透阈值。该候选不再需要对六个新碰撞体进行凸包烘焙；原生形状类型和完整运动结果分别检查。

### 控制周期内关节目标过渡（运行目录r06）

原生盒几何r05仍在入口／末端出现约0.056／0.051 mm的瞬时穿透。r06增加显式`joint_target_interpolation=linear`：把7个操作臂关节目标在每个100 ms控制周期内逐步过渡到终值，非操作臂和夹指仍保持固定目标。旧传递包未指定该字段时保留原执行方式；本轮几何、摩擦、力和穿透阈值不变。入口试探前先移动到距入口约1 mm的外部位置，随后缓慢试探。

这组控制对照也没有消除入口越限，两侧约0.05577／0.05586 mm，故均停止并判失败，没有在保护失败之后清除终止标记来凑出恢复成功。此次有界调查到此收束：新几何在局部能表达入口阻挡与内部通行，但完整机械臂的接触数值／测量口径仍未验收，不能继续把策略失败简单归因于示范不足。

后续应先对照接触点分离量与真实几何重叠、碰撞时刻实际位姿和求解器响应，验证瞬时越限的来源。当前只有控制区间末位姿和区间最大接触点穿透，不能据此断言峰值全是数值伪影，也不能把0.056 mm直接解释成实物变形。原0.05 mm判据和所有失败证据保留，不通过降低阈值要求来宣布完成。

## 本轮最终结果

最终r06配方的**局部检查5/5通过，机械臂检查1/3通过，整体未验收**。五项局部正常／反例、两侧机器人恢复尝试、对准的半步长机器人回合全部实际执行；受监督子进程中6项退出0、两项保护失败退出1，监督器退出0不等同所有子项成功。

| 检查 | 结果 |
| --- | --- |
| 局部对准插入／退出，0.2 ms及0.1 ms | 两组均通过 |
| 局部横偏±1 mm、偏航+2° | 三组均在入口附近受阻，反例通过 |
| 机器人+1 mm偏移恢复 | 未通过；入口接触点穿透指标峰值0.05577 mm，超过0.05 mm保护阈值，未执行后续恢复 |
| 机器人−1 mm偏移恢复 | 未通过；相同指标峰值0.05586 mm，未执行后续恢复 |

通过的机器人回合在5～50.28169 mm内部检查区间有287个控制样本，接触指标和子步峰值均为0，深度持续增加。插入过程最大接触点穿透约0.000138 mm。**末端仍有约13.67 N的子步力模长和峰值**；相应控制区间均值最大约0.08834 N，而10 Hz控制采样值为0。两种采样口径不能混淆，本轮10 N门槛仅施加于控制采样值，不等于全过程每个物理子步低于10 N或真实设备安全认证。

这证明当前理想化候选可表达“对准后内部通行”，但没有完成可靠的“入口受阻→退回→纠偏→重插”机器人闭环，也没有通过实物力学标定。旧BC／RL成绩不变，本轮没有重新训练或评价学习策略。
