# System0初始偏移与倾斜鲁棒性

2026-11-26，用户要求初始末端不再正对插口，加入位置偏移、俯仰及方向误差后重试。本轮保留已训练权重，新增显式初态评估入口；未重新采集训练数据、未更新模型或自动切换视觉资产。

## 模型与条件

使用此前配对实验训练种子341000的两个最终模型（该种子原24目标测试为路径24/24、无路径20/24），避免再次只选无路径失败种子。两组先BC20000，再经历12000有效在线交互；配对恢复原因及11999在线更新见[主实验](system1-path-ablation.md)。本轮固定插口世界XY为+0.5／+0.5 mm、yaw=0，共10个条件，种子360000～360009，左右完全配对。每回合最多900步，GT参考、腕力、奖励、动作和任务判据保持，teacher requests全部0。

除原始起点外，先构造尖端在孔口外10 mm的对正基准，再在两接触垫包围盒中心的中点施加横移／抬高，以及绕夹爪中心的yaw后pitch旋转。坐标X向前、Y向左、Z向上。10 mm是旋转前的尖端间隙；旋转后的实际间隙另行测量，不能把夹爪中心位移等同于尖端位移。模块仍固定于夹爪，不包含夹持滑移。

初始化使用离线原厂IK放置真实关节，经历原有3步物理稳定，之后才开始第0步观测。没有规则控制器预先对正，没有准备动作被算成自主成功。所有新初态实际实现误差低于0.1 mm／0.05°，初始盒体重叠为0、实际尖端间隙大于2 mm；配对初始TCP位置与旋转一致。
