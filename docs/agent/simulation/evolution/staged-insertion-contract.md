## 实际修改

输入为`/data/omi_runtime/runs/smooth_guide_20261122/r06/robot_transfer`，仍是WG-r10＋OM-r08、右臂水平停放、固定附着的六盒代理。视觉、碰撞几何、摩擦0.2、质量、关节和相机均不改，碰撞全程启用。既有内壁已是连续平面，因此这次首先调整任务判据和接触统计，不继续改网格或降低摩擦。

新合同名`entry-strict-interior-tolerant-v1`。**“入口严格”指对准资格和实体阻挡，不是碰一下就判整回合失败。** 偏置应被挡住，并允许真实退回纠偏；只有符合资格后才能采用内部标准。

| 阶段／检查 | 当前实验配置 |
| --- | --- |
| 入口资格 | 深度1～5 mm区域内，横偏<0.15 mm、角度<0.003 rad，至少3个连续控制样本合格后、深度达到5 mm才进入内部阶段 |
| 防绕过入口 | 深度超过6 mm仍未通过资格即失败；退回到1 mm以下需重新取得资格 |
| 入口持续接触负载 | 100 ms区间平均指标>5 N连续3次才硬终止；初次超限或受阻先给恢复提示 |
| 内部持续接触负载 | 同一指标>20 N连续5次才硬终止，小幅短时接触不直接判失败 |
| 大异常 | 平均指标>50 N立即终止；入口／内部接触点穿透峰值分别>0.08／0.15 mm终止 |
| 几何补充检查 | 控制时刻原生盒几何重叠>0.1 mm终止；内部明显丢失导向姿态仍终止 |
| 到位 | 已通过入口；深度误差<0.1 mm、横偏<0.25 mm、角度<0.005 rad；控制区间内有肩部接触，且相邻控制时刻深度变化<0.03 mm，连续3次稳定 |

这些是**仿真任务假设，不是真机额定力或安全阈值**。力指标来自接触报告冲量模长之和的区间平均，不等于真实腕部净力；原始末子步采样、子步峰值、接触点分离量继续保存。几何重叠用盒体SAT诊断，取自控制时刻，不能据此断言控制间隔内从未穿透，也不能直接与子步最大接触点指标互相替代。

卡在入口且持续无推进会给`recovery_required`，不直接变成成功或强行移动物体。硬异常一旦判失败必须reset才解除；恢复到入口外只是子目标，不算插入成功。
