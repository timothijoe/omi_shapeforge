# 001：外观与初步碰撞体分离

状态：accepted。范围：当前光模块场景导入和落台原型，不覆盖精细接触。

现有 `.blend` 提供丰富几何，但密度、质量、惯量、摩擦和柔性缺少实物标定。为先验证模型单位、两种场景格式及运行通路，保留逐部件外观网格，使用刚性配准 mesh 的 bounds 生成单一碰撞盒，并显式记录假设参数。

优点是两个引擎能使用相同简单输入，容易核对尺度、下落和支撑；代价是碰撞盒封住凹槽，拉手不弯曲，示意轨道也不是实际夹具。不得把当前通过结论延伸为夹持／插接或物理精度验收。

后续如需这些任务，应选择能保留接触区域的分件凸体／显式几何、明确惯量与接触参数，并重新验收。替代方案尚未实现。当前结构见[引擎能力](../evolution/engine-scenes.md)。
