# ADR 002：以 Blender V3 为主资产，V2 为辅助参考

日期：2026-11-20。状态：采用。依据：用户明确要求“blender 的这个我们叫做 v3，然后重点使用 blender，v2 作为 v3 的辅助和对比”。

## 决定

- Blender 建模路线正式命名为 **V3**，当前连通槽模型作为 `OM-001/V3` 的 `r01` 基线；原目录名 `OM-001/GROOVE-r01` 保留为别名。
- Blender 是后续几何编辑、部件组织、尺寸修正和资产导出的主工具；主工作文件为资产登记表中的 `primary_authoring_file`。
- V2 保留为辅助参考与对比基线，用于核对结构、尺寸和观测差异。历史 V2 不因本次决定被覆盖或重新解释为 V3。
- 照片稿与双目尺寸稿保留为 V3 建模路线的历史阶段，不同时宣称它们都是当前 V3 主文件。

## 文件与版本

原 `connected_groove.blend` 继续保留在迁移输入中。本次复制一份冻结的 V3-r01 和一份可编辑的 V3 工作文件；三者初始 SHA256 相同。完整路径、哈希、旧名映射和实例绑定见[资产登记表](../../../../manifests/optical_assets.json)。

后续编辑工作文件，在形成可交付几何时创建新的 r02／r03 冻结副本，记录父版本、改动、导出物与验证，不覆盖旧修订。派生 OBJ／MJCF／USD 继续放在外部新目录，并记录实际源文件哈希。

已有单模块与 2×2 场景的来源就是这份连通槽几何，目录中可以关联 V3-r01；历史报告和场景清单仍保留当时名称与哈希。今后新修订需要重新导出和验证，不能自动沿用旧场景的通过结论。

## 边界

本次是用户授权的版本命名和开发主线调整，没有修改几何、重新估计尺寸或提高精度声明；也不改变 Python 包版本和旧实验目录中的 v3 等试验编号。V3 的槽结构已参考 V2，来源关系继续如实保留。
