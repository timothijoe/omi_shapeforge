# 2026-11-20：圈选后凸体、原 mesh 与原生深度复核

用户进一步圈出两个完整后凸块，说明背面应平，随后要求查看原始生成 mesh 并对照 RealSense 尺寸。这纠正了上一阶段仅处理端面装饰、把方块主体说成已确认实物连接器的解释。

新增 r02 将两块 body Y=−73 mm 的外沿裁回既有白壳后平面 −64 mm，封闭切面，保持其余部件。保留 r01 和迁移原件。两份 Blender 独立重开、闭合性与退化面检查通过；GLB 零错误零警告。135 个装配 mesh 中仅两件改变。

随后在相同米制坐标下比较原 28 帧 TSDF、人工清孔 SDF、r01 和 r02。原始后部更低矮、模糊，不能支撑规则的两个 9 mm 方块；但仍有局部后伸结构，不能说观测已经证明完全齐平。r02 的平背面来自用户要求，作为候选保留。

原 MCAP 仍包含 RealSense 原生深度。本轮提取与既有 28 帧精确同时间戳的 16UC1 深度，复跑可见面尺寸审计，并另跑冻结 FoundationStereo 深度缓存作对比。原生深度的壳宽为 62.92／63.49 mm、壳长 65.52／65.88 mm；双目缓存相应为 63.94／64.60、65.32／66.29 mm。两个数字表示严格／宽松门限的条件估计，非真实误差区间。原 TSDF 局部面估计为宽 60.89、长 64.37 mm，显示重建平滑和方法差异不能忽略。当前模型名义宽 62、长 65 mm；底面和孔内沿支持不足，21 项均未通过两定义面稳定性规则，未据此做确定尺寸改版。

同尺度 Blender 对照已保存并在桌面显示；最新路径与报告以[插接座能力](../evolution/optical-socket.md)和[资产清单](../../../../manifests/socket_assets.json)为准。未运行新 GPU 推理、碰撞、训练或硬件控制。
