# 2026-11-21：V4双脚胶件与高度纠正

用户补充两张装入／取下照片，指出黑色胶件向内部延伸且有三个金属片。r02将r01固定黑色盲凹块改为单独连通的双脚胶件，加入三个金属凸片并切出内部接收空间；窗口展示后，用户指出胶件和金属片过高，并确认应沿高度方向下沉。

重新查看原视频侧面／斜侧面，生成独立r03，四个部件整体下沉1.5 mm，容纳槽同步重新构建。该量是视觉修正估计，未宣称实物测量。r02保留但不作为当前版。

r03共18个mesh，16个闭合实体与2个开放装饰折缝；胶件双脚连通性、下沉位移、主体18.1 × 8.2 mm和前端8.0 mm、文件重开均检查通过。向外拔出0–15 mm的31个离散位置未发现胶件／主体表面碰撞；非连续路径认证，也不是橡胶接触仿真。599个旧文件哈希未变。
