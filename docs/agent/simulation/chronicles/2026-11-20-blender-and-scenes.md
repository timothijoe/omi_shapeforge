# 2026-11-20：Blender 资产和双引擎场景

依据[仿真验证索引](../../../../manifests/simulation_validation.json)和提交 `a12c225`。本轮文档整理复核这些证据，没有重新运行渲染／物理批次。

便携包给出 Blender 4.5.16 LTS 的原机版本。本机安装官方 Linux 包并验证 SHA256，四份保存模型的重开、内嵌资源和单位检查通过；当前连通槽模型完成一张后台渲染。随后求值导出 15 个可视部件。

同源资产生成单模块和 2×2 的 MJCF／USD。MuJoCo 3.3.7 完成加载、EGL 图像、240 步／2 秒落台稳定；Isaac Sim 5.1.0 完成本地 USD 和 CPU PhysX 的对应测试。最终方阵报告保存场景和运行脚本哈希。

前期 Isaac 通用启动曾触发依赖下载并超时；之后改为本地扩展的精简启动，显式 attach stage 后进行物理步进。最终通过记录与失败尝试分别保留，不能混用。

该阶段采用包围盒碰撞、20 g 假设质量、摩擦 0.6 和示意轨道；没有槽接触、柔性、真实机器人／夹具、RTX 图像或 GUI 验收。`omi_proj` 的文档已审阅，但相应 Git 外模型尚缺。

该阶段证明资源与基本引擎通路可行。当前有效事实见[资产能力](../evolution/asset-pipeline.md)和[引擎能力](../evolution/engine-scenes.md)。
