# 2026-11-20：插接座后部 RealSense 观测核对

用户将带孔装配体命名为光模块插接座，随后指出后部似乎补建了多余结构，要求对照采集的 RealSense 数据修正。

本轮检查对应的 28 帧原始彩色图和后部 12 帧已有双目深度缓存。原始彩色图确认一黑一银两块连接器存在；旧细化脚本为它们增加的黑色端面覆盖片和各 12 个金色触点缺少足够依据，银色件端面外观也与 RGB 不符。以此生成 OS-001 的 `r01-rear-review` 候选，移除这 26 个部件，135 个保留件几何与材质引用一致，孔口未变。

反光区域深度存在回落和帧间变化，没有据此重估尺寸，也没有因不可见而删除孔内隐藏结构。两块连接器主体及内部后方结构仍需进一步细化；本次不宣称完整后部重建。

独立装配体和 V2 插入组合场景均另存并独立重开。135 个装配部件闭合、无退化面，GLB 零错误零警告。原模型和 V3 保留；原插入动画的放置含义与局限不变，碰撞未复验。

一次生成组合场景时漏传 `--insertion`，导致备用 V2.1 的显示状态及输出命名不合适；该次产物整体保存在运行目录 `superseded_insertion_wrong_mode/` 并标记不可使用。正式组合场景已用正确模式重新生成，脚本增加源类型与模式一致性检查。

当前入口、证据与边界见[能力记录](../evolution/optical-socket.md)和[资产清单](../../../../manifests/socket_assets.json)。本轮未运行 GPU 推理、训练或硬件控制。
