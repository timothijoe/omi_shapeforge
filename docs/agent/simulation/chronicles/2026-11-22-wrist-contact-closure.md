# 2026-11-22：纠正“无穿模等于夹住”，建立双胶垫接触

用户在WVA-01命名后指出：模块的夹持位置可变，但夹紧时两侧黑色胶垫必须接触，并随夹爪保持相对位姿。检查发现旧参考装配仍有左0.046／右0.602 mm间隙，工具没有启用接触，因此旧“无相交”只能说明没有穿模。

新增GC-r01独立夹持场景，保留全部源mesh及WVA-01。两指增加开合关节和限力伺服，原黑胶垫凸网格参与碰撞；模块为6自由度刚体，无焊接附着。先后保留软接触滑移、直接mocap运动丢失夹持的失败，最终使用动态工具基座跟踪目标，模块靠接触／摩擦保持。

名义及4种偏移／倾角初态均通过闭合、重力保持、22.36 mm平移和张开释放；保持／移动阶段每10 ms双侧法向力采样全部通过，最大相对滑移约0.00464 mm，半步长复验通过。实际可见网格审计确认只有两块黑胶垫与模块接触，数值压入约1～3微米；源资产哈希未变。

这些是局部仿真夹持结果，非真机标定或插入成功。插槽碰撞在此单测关闭，质量／摩擦／刚度是试验参数，未新增机器人或策略验收。新场景含已夹紧关键帧、接触状态查询和丢失双侧接触时的停止门控。
