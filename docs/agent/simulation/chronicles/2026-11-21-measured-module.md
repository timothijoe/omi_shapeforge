# 2026-11-21：独立实测截面光模块

用户报告模块横向18.1 mm、厚度8.1或8.2 mm，并补充下部前伸段向上倾斜、尖端厚度8.0 mm，要求不干扰旧mesh。

已从V3派生OM-001/MEASURED-r01，选择8.2 mm主体厚度，下唇上翘0.2 mm；斜面长度暂沿用旧几何的5.193792 mm，未作为实测。导出独立Blender、OBJ／MTL和GLB。

实际切片复核主体／斜面中点／下唇尖端为8.2／8.1／8.0 mm；101点斜面单调性通过。13个实体部件闭合、法向一致、正体积且无退化面；2个装饰开放折缝仅作外观。三种文件重开通过，503个旧文件哈希不变。新副本中清理了原侧弹片的重合顶点及退化面。

当前没有替换训练资产、调整插座或重跑动态插入。持续事实、文件和尺寸图见[独立实测模块](../evolution/measured-module.md)，证据入口见[资产清单](../../../../manifests/measured_module_20261121.json)。
