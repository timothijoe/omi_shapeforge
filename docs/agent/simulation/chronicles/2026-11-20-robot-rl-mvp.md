# 2026-11-20：真实 URDF 场景和 RL 环境骨架

用户提出构建类似照片的机械臂插接仿真环境来调试 RL，随后强调先评估难度、记录整体架构、尽快做简单版本，并明确第一版也应使用已有机械臂与 URDF。

本轮导入完整厂商双臂 URDF，保留 14 个机械臂关节、4 个滑动指关节和 2 个 mimic 等式。仅在派生 URDF 中移除两个零体积 TCP 显示标记的 visual/collision，保留坐标架；原文件及网格未改。生成圆桌与插接座 r04／V3 参考场景，已保存 EGL 预览。

`RobotReachEnv` 使用 6 维 TCP 增量、DLS IK 和位置伺服。在两个重置种子下，脚本到达检查各 31 步达到约 2.64 mm 误差，起始误差约 17.4 mm。Gymnasium checker、非法动作拒绝、非主动臂保持检查通过。当前采用重力补偿，机器人接触明确关闭；工具 TCP、抓取关系、接触插入与 RL 训练均未验收。关节模型是真实 URDF，不是替代机械臂的笛卡尔代理。

另建的原始简化插入夹具保留为自动回归：4 项行为测试通过，Gym checker 与“脚本插入成功／偏置碰壁不成功／零动作超时”三场景通过。它不作为主机器人任务。标准库控制层 14 项测试通过，4 项可选仿真测试在控制环境跳过，并已在仿真环境单独执行通过。

架构、难度及 M0–M4 计划已保存于[开发计划](../../../design/robot-rl-development-plan.md)，启动方式见[教程](../../../../tutorials/robot_sim_mvp.md)。没有连接硬件，没有修改 omi_proj，也没有启动学习器。
