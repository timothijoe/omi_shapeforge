# 2026-11-20：桌面网格查看兼容性修复

用户反馈网页可打开但网格空白。真实桌面截图显示 Chrome 无 WebGL；之前启用软件 WebGL 的无头测试未覆盖此条件。

增加 CPU 三角形逐像素深度渲染后备路径，保留原网格及交互。禁用 WebGL 的检查确认四网格可见、旋转、缩放与部件选择有效；刷新用户桌面窗口后，通过真实桌面截图确认四网格显示。原模型与内嵌网格数据未改变。

证据见[兼容性验证](../../../../manifests/viewer_compatibility_validation_20261120.json)。这是显示兼容修复，不改变模型尺寸或物理精度结论。
