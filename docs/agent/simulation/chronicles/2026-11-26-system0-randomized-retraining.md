## 中断与修复

无路径431000在19086次已确认交互后，第三次请求恢复时抛出`recovery_attempt_budget`；有路径431000已记录19445条learner交互，worker另有1条已执行但未回传。最近完整检查点都在15000步，未保存的后续分支不能当作已恢复模型状态。

根因是恢复老师完成两次恢复并回到idle后再次受阻，耗尽预算只在下一次teacher查询才检查。修复将这种失败放在刚发生的真实step后终止，沿用既有失败奖励和reset流程。没有扩大恢复次数、放宽判据或补造动作。以原失败观测离线复现，回归44项通过，轻量29通过／75跳过。

原冻结`code/`保留，新的`code_resume_training/`只改`isaac_recovery.py`。第二对从同一15000步检查点恢复各5000步，保存频率提高到1000步。模型、优化器、旧经验池保留，物理回合重建；初始化种子仍431000，续训episode seed是432000。
