# 2026-11-20：孔宽与模块宽的双向证据复核

用户质疑 18.60 mm 通道是否有图像／点云依据，指出模块也可能有误，并要求显示下半部分。已明确 r03 只是一项视觉贴合假设，没有支持该数值的独立定量拟合，不应被当作已确定修正。

追溯 V3 的 59 视角截面拟合来源并回算其逐帧统计：基准主体宽 17.542 mm 对 21 个合格留出帧的截面 RMSE 复现为 0.884 mm。保持原通道、仅放大模块以取得同样窄间隙，需要外包宽 20.474 mm、主体约 19.762 mm，固定厚度留出 RMSE 变为 1.746 mm。此比较只约束旧模型假设下的大幅模块放宽，不排除模块小幅偏差、共同尺度偏差或双方问题，也不认证收窄孔宽。

Open3D 已切回 r01 原孔宽基准，默认显示完整下部白色支架；新增显示开关并核对桌面。几何源文件未修改，r03 保留为对照。报告与截图位于 `/data/omi_runtime/runs/width_evidence_20261120T081118Z/`；当前解释见[V3 插入能力](../evolution/v3-insertion.md)。
