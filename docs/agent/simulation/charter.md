# 仿真总章程

## 目标和职责

将可追溯光模块几何转为统一米制资产，在不同仿真引擎中建立可检查的场景，再逐步接入完整机器人与真实夹具。

## 长期约束

外观、碰撞、质量惯量、摩擦和坐标变换分别记录来源；示意结构与实测资产分开标识。保留输入与旧结果，不在原模型中保存实验修改。碰撞代理能落台，不代表精细插接或夹持可信。

引擎验证分别覆盖资源加载、后台物理、渲染、GUI 和任务表现；一个引擎的图像不能证明另一个引擎已渲染。机器人模型须先核对网格引用、关节、工具和单位，再考虑任务控制。

当前能力分别见[资产管线](evolution/asset-pipeline.md)、[双引擎场景](evolution/engine-scenes.md)和[机器人资源](evolution/robot-assets.md)。
