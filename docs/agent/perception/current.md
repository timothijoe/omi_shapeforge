## 当前目标与约束

在已知面向和粗位姿先验下，利用模块自身可见结构，持续估计部分插入/遮挡过程中的模块相对插口位姿。

- 不使用额外黑白 marker；该分支已停用，不再等待标贴身份或贴位确认。
- 不使用绿色挂件；刚性黑色端壳可作为结构候选。
- 不把夹爪或遮挡边界当作模块边缘；归属不清的点先剔除。
- 不以低残差、IoU 或稳定轨迹代替真实六维精度。
