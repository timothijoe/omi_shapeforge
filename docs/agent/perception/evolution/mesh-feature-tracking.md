# 光模块模型特征与鱼眼跟踪

> 本机迁移提示（2026-11-24）：运行资源实体已迁至 `/data/shapeforge/runtime`；本文中的 `/data/omi_runtime` 是保留的兼容入口，指向同一份内容。目录映射与恢复要求见[当前资源契约](../../interfaces/local-resources.md)。

后续用户明确禁止使用额外 marker。本文的标贴/纹理相关内容为历史试验，不再等待贴位确认或用它初始化。当前主线见[无 marker 结构线开发](../chronicles/2026-11-21-markerless-structural-features.md)。

## 当前能力边界

已实现离线工作原型：在给定初始位姿和面向下，选择模型头部范围内的图像角点/纹理，将候选点映射到 mesh，按鱼眼标定跟踪，并区分视觉更新、先验辅助、短时预测和丢失。

**精确三维特征绑定尚未通过验证，默认不启用自由六维更新。** 实验中发现依据完整轮廓得到的初值会使某些图像特征映射到模型端面/内层；仅使用头部候选点放开六维更新也出现明显漂移。低重投影残差不能排除这种错误。当前默认输出的更新只有相机 X/Y，深度和旋转明确保留先验；不能作为已验证的精密插入位姿。

## 已实现接口

- `scripts/perception/mesh_feature_tracker.py`
  - `FisheyeCamera`：原分辨率局部图和 episode ROI 的双向像素映射、鱼眼射线与投影。ROI 使用已核对的 `389×389 → rint(linspace) → 128×128` 采样。
  - `MeshSurface`：在固定网格上做射线相交，记录表面身份。模块绿色挂件与内部简化块不用于特征绑定，默认进一步限定到刚性头部。
  - `MeshFeatureTracker`：Shi–Tomasi 候选角点、参考图锚定 LK、正反向检查、固定局部纹理 NCC、局部找回、头部模板 fallback、给定面向的局部位姿求解。
  - `save_reference_pack`：保存 2-D/3-D 候选对应、图像小块、初值及表面身份。它是候选绑定记录，不是测量真值。
- `scripts/perception/run_mesh_feature_tracking.py`：实际视频/episode 准备、SAM2 可见主体分割、跟踪与受控遮挡检查。`--experimental-se3` 明确启用尚未验收的六维更新，默认关闭。
- `scripts/perception/render_mesh_feature_tracking.py`：特征图册、原图投影和视频。灰虚线/叉为模型推算，丢失时不显示为新观测。

跟踪器不会把被插座挡住的边界直接当成模块端部。仅匹配仍被观测支持的参考特征，模板与三维锚点不在每帧随估计漂移而重新建立。匹配不足时保留预测来源，超过短时窗口进入 `lost`，`T_camera_from_model=None`；单独保留的显示预测不能被当作当前测量。

原型有 `initializing`、`observed_update`（实验六参数拟合）、`prior_assisted_update`、`prediction_only`、`lost`。必须同时读取 `measurement_dof_count` 与 `pose_update_mode`，不能只取矩阵而忽略深度/旋转来自先验的事实。条件 Jacobian 方差仅为数值诊断，排除了初值、模型、标定和相关特征偏差，不是物理置信度。

默认模式直接约束的是图像 u/v；把它换算为相机 X/Y 也依赖保留的深度和模型绑定，不是独立的毫米级平移测量。

## 实际验证

在六秒原始鱼眼视频中使用原分辨率局部图，保留原始镜头投影模型；采样 61 帧。最终默认模式提取到 21 个模型头部范围内候选特征，随后 60 帧有二维更新。三段真实 episode 共 541 帧，128×128 输入只保留 3/4/3 个头部候选点，分别有 70/47/55 帧先验辅助二维更新，其余为初始化、短时预测或丢失。没有得到可靠的六维结果。

另将**同一原始视频、同一初值**按真实发布器规则缩到 128×128，当前头部特征方法因少于 3 个可用点而初始化失败。这是当前方法的受控分辨率对照，不是证明任何算法都无法使用 128×128。

静止图像及运动视频的受控遮挡分别检查：前端遮挡但保留头部特征时仍可更新；全部遮挡时不产生新的视觉更新，进入丢失；重新露出后可找回。运动视频的前端阶段为 16 帧二维更新，全遮挡阶段误报更新 0 帧，重新露出后的 23 帧恢复更新。该测试显式保留头部特征，并不是实际插入采集或六维精度测试。更强、同时覆盖头部的遮挡版本会丢失，结果也保留。

六维数值求解器另在合成的已知三维点投影/噪声上检查，证明其坐标和求解代码能够运行；不能替代真实图像对应或位姿精度验证。

## 关键未完成项

1. 核对实际图像特征在模块表面上的真实固定位置，不能继续完全依赖不准初值的射线绑定。
2. 扫描参考与鱼眼视频的黑白标贴外观在旋转 180° 后较相似，但尚未确认是同一实物标贴且贴附位置未变。在确认前，不能直接将扫描中估计的标贴三维位置当成鱼眼中的已知对应。
3. 给定可信绑定后再验证连续六维更新、真实部分插入与滑移；目前不能把默认二维稳定性包装成六维准确性。
4. 插座特征/位姿及两端相对位姿尚未在这轮跟踪器中验证；局部几何计算函数已存在，但不以缺少可信输入的矩阵计算插入成功。
