# 用户确认目标的固定尺度配准

## 输入与边界

`optical_module_portable_20261119.zip` 是独立 CPU 小工程，包含三张照片、10 万点已有点云、已确认 ROI、固定配准 mesh、模型和脚本。`quick` 包只用于快速查看；其五个主要交付文件与 portable 对应内容一致。两个包均通过内部哈希与 ZIP 校验，见[便携复验记录](../../../../manifests/portable_validation.json)。

当前输入已经包含用户确认的目标区域，不执行全场景目标发现。旧错误目标的低残差已撤回，不作为光模块匹配证据。HTML 来源点云不是原始双目图，无法从该包恢复原始标定／录制。

## 数据流和方法

包内 `scripts/run_demo.py` 先调用 `portable_match.py`，再调用 `render_overlay.py`。固定模型和尺度，围绕头尾／正反及位置偏移产生 36 个初始化，以稳健点到面 ICP 优化，保留近似不同候选并输出自包含 HTML。

原始选区 486 点，平面过滤后 472 点；121 个检查点未参与 ICP，但 ROI、方向和初始化依赖整体观测，不能视为严格独立测试。全部原始点的统计必须与检查子集一起报告。

## 本机复验

在 GPU 隐藏的 CPU 进程中，使用 NumPy 1.26.4、SciPy 1.17.1、Open3D 0.19.0，实际执行了配准、HTML 生成和包内独立复查：

| 项目 | 当前结果 |
| --- | ---: |
| 检查点中位表面距离 | 0.147922 mm |
| 检查点 P90 | 0.731328 mm |
| 全部 486 原始选点中位数 | 0.149174 mm |
| 全部原始选点 P90 | 2.770541 mm |
| 检查中位数／P90 与原参考的差 | 两项均为 0 |

位姿矩阵最大元素差约 `2.22e-16`，属于该样例浮点舍入级差异。原始 10 万点在新 HTML 中保持，固定尺度刚体变换检查通过。结果文件和解释见[配准教程](../../../../tutorials/portable_registration.md)、[数据格式](../../interfaces/data-formats.md)。

## 模型来源与未验证部分

旧工程从照片解释结构、按冻结观测修正尺寸，再按用户授权参考 V2 修正连通槽。上述建模历史是原包说明；本机已重开模型、渲染和导出，尚未从 59 帧重新估计尺寸，也未重跑全部照片／槽构建阶段。

头尾和正反仍有近似多解；局部收敛、残差或条件重复性均不等于真实六自由度精度。物理精度、传感器／标定偏差及新场景泛化均未认证。阶段记录见[便携包复验](../chronicles/2026-11-20-portable-registration.md)。

## 完整工程到达后的新增核对

2026-11-21 用户再次指定同一源 HTML 和同一目标圈选：已从当前 V3 部件导出网格，核实 9 部件拟合主体与旧 portable 网格完全一致，重跑配准并显示完整 15 部件（含拉手）。默认依据插入端朝插座、拉手朝夹爪的场景先验选择头尾，保留正反面候选；实际验证 Chrome WebGL 查看与控件。默认解检查子集 P90 0.728 mm，全部原始 ROI P90 2.752 mm，不新增物理精度认证。见[阶段记录](../chronicles/2026-11-21-v3-pointcloud-overlay.md)。

01 工程结果快照已独立恢复，旧 V2 冻结几何回放已在本机通过；它重建冻结参数和已保存位移，不是新点云配准或从传感器重建。V2.1 和带孔对象的资源也已到达，但未自动替换当前便携包模型。具体阶段见[工程到达记录](../chronicles/2026-11-20-full-project-arrived.md)。

用户随后纠正正反面：当前默认采用槽面朝采集相机的候选，头尾保持不变；新检查子集／全部原始 ROI 的 P90 分别为 1.111／1.296 mm。见上述 2026-11-21 阶段记录的纠正小节，旧结果不覆盖。

新增 OS-001 r04 的独立粗配准与 V3 联合显示，挂件排除。插座检查点 P90 4.31 mm、原始选区 P90 11.33 mm；双孔/金属通道对应未确认，未强制插合。见[插座阶段记录](../chronicles/2026-11-21-socket-cloud-and-video-to-data.md)。

2026-11-21 已实际试跑 V2D SAM2/MoGe/FoundationPose。预测深度下的两条官方位姿分支失败；SAM2 掩码驱动的自编有界像素精修改善投影贴合（61 帧均值 IoU 0.657→0.914），未接入头部点云外参、未认证真实 6D 精度。见[实际试验记录](../chronicles/2026-11-21-video-to-data-wrist-trial.md)。

最新已实际在原始双目采集上测试点云初值＋像素联合精修：11 组新算深度，初值不依赖旧物体位姿；平均 RGB IoU 0.814→0.918，检查点 P90 逐帧均值 0.344→0.371 mm。像素单独优化会把检查点 P90 提高到 2.287 mm；保留联合几何约束。4 帧近似候选待核对，数据重用与精度限制见[阶段记录](../chronicles/2026-11-21-stereo-cloud-pixel-trial.md)。

用户随后否定该双目位姿质量。局部结构复核发现 0885 存在约 75 px 的附着标贴跨帧错位，整体 IoU／点云残差未排除错误朝向。扩大候选也会引入其他翻面错误，当前结果未通过结构验收；人工结构点辅助仅为诊断。见[复核记录](../chronicles/2026-11-21-stereo-pose-structure-review.md)。

用户允许正反面作为先验，但要求精确连续位姿。固定面向后的局部纹理＋端部约束试验已有改善，三个视角仍有约 2.8–3.5 px 的检查角点偏差、约 5–7 px 的端部轮廓 P90，未达结构验收。见[固定面向试验](../chronicles/2026-11-21-known-face-fine-pose.md)。

用户明确下一主线为操作过程中可部分遮挡的局部插接几何：mesh 绑定可见刚性视觉特征，加面向和夹持先验，连续估计模块相对插口的位姿。局部坐标换算已有合成检查，遮挡跟踪尚未实现/验证；见[设计与当前边界](../../../design/visual-insertion-local-tracking.md)。

后续已建立参考特征记录与鱼眼跟踪原型，但依据初值的射线绑定仍有表面身份疑点，自由六维更新出现漂移。当前采用明确的二维观测/深度角度先验状态，不把稳定性当作精确位姿；见[特征跟踪能力](mesh-feature-tracking.md)。扫描与鱼眼标贴的物理贴附关系待用户确认。

用户已要求忽略附加黑白标贴，相关确认问题取消。当前无 marker 结构线原型在 61 帧生成候选，但杆身遮挡后的六维更新仍不可靠，已加保护，不得作为精确插入定位；见[结构线记录](../chronicles/2026-11-21-markerless-structural-features.md)。

结构线原型的右侧头部候选被用户指出可能混入夹爪。已增加独立的模块/端部/夹爪分割和归属过滤，61 帧均不再使用该不确定线，仅保留四组。低残差不代表精确位姿；见[归属修正记录](../chronicles/2026-11-21-structural-edge-ownership.md)。
