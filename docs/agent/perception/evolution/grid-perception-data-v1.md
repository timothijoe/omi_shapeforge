# 感知细网格数据 v1：有边界的分层枚举

用户希望为observation shaping准备充分、精细的感知预训练数据，并要求先明确界限，再细粒度采样与标注。本版按已确认的光模块三个变量实施；插座与模块关系分层覆盖。范围是本版工作范围，不是实物机械极限，也不是预测精度承诺。

阅读入口：[阶段编年](../chronicles/2026-11-23-grid-perception-data-v1.md) · [操作与恢复](../../../../tutorials/grid_perception_data_v1.md) · [机器清单](../../../../manifests/grid_perception_data_20261123_v1.json)。

运行：`/data/omi_runtime/runs/grid_perception_20261123_v1/`。采集、逐图标注审核和严格三变量子集导出已完成。结果窗口：`http://127.0.0.1:8895`。本轮不训练模型。阶段先采用接近＋孔口前对齐，不生成插入后的样本；插槽接触未因此得到验收。

## 界限与粒度

| 项目 | 本版范围 | 间隔／档位 |
| --- | --- | --- |
| 模块前后（工具Z） | −3～+3mm | 0.5mm，13档 |
| 模块上下（工具X） | −1～+1mm | 0.25mm，9档 |
| 模块俯仰（绕工具Y） | −4～+4° | 0.5°，17档 |
| 尖端相对孔口左右／上下 | −3～+3mm | 0.5mm，各13档 |
| 孔口附近左右／上下 | −1～+1mm | 额外0.25mm，各9档 |
| 孔口前轴向距离 | 0.5～40mm | 0.5、1、1.5、2、3、4、5、7.5、10、15、20、30、40mm |
| 三个相对转角 | 各−6～+6° | 1°，各13档 |

模块保持左右居中、偏转／侧倾固定，参考点和R0沿用[用户确认的三变量预览](three-variable-grasp-preview.md)。上述前后／上下均相对预览零位。插座参数描述模块在插座坐标系中的相对姿态：X左右、Z上下、Y为轴向；功能孔中心为`(−0.3,1.85,0.3)mm`，尖端参考点为模块系`(0,−35.0931697,0)mm`。转角使用该相对旋转的XYZ欧拉角，不是腕部坐标中的绝对欧拉角。

采集时插座固定在世界坐标，通过机械臂IK改变相对观察关系。点位单位米，角度档位单位度，像素采用完整960×540鱼眼图内参。0.25mm步长表示采样密度，不表示真机能分辨或定位到0.25mm。

## 覆盖方式与规模

- 模块13×9×17＝**1989个夹持格点完整枚举**，每格配六种确定性的插座相对配置。
- 模块零位下完整枚举插座平移13×13×13组合。
- 模块零位、孔口前10mm处完整枚举三个转角13×13×13组合。
- 模块零位下，孔口前0.5／1／2mm额外采样左右／上下0.25mm细网格。
- 相同完整组合去重后，**16490个候选视图**。这不是全部九变量的完整笛卡尔积；`coverage_families`明确记录各样本属于哪些覆盖层。

每个候选都要得到“有效样本”或明确拒绝原因；穿模、夹持不合格、实际姿态偏离、IK失败、可见像素不足不能静默跳过。有效范围可能依赖变量组合，尤其是小距离与大横向偏移的组合。

## 物理与几何检查

使用冻结GC-r01／WG-r15／OM-r08和SIM-r06视觉插座，不修改源mesh。每个模块格点经历自由模块闭合和重力保持，沿用0.2ms物理步长、1.2s总过程，0.8～1.2s每5ms检查双侧力、滑移和转角。可见网格独立检查胶垫距离和其他夹爪部件穿插。

每个观察视图从已验证夹持状态独立初始化到IK目标，模块仍为自由刚体，在重力下再稳定0.1s，最后0.05s每5ms检查双侧接触。再检查实际模块三变量约束、夹爪／模块与完整插座mesh不相交，以及模块所有原始网格顶点未越过孔口参考平面。插槽不参与物理接触求解，因此本版只采孔口前静态视图，不宣称连续机械臂轨迹或插入验收。

为加速采样，物理模型去除无碰撞视觉几何，保留碰撞网格、动态关节及惯性；工具、双指与模块的质量、惯性、惯性坐标与原渲染模型逐项一致。渲染模型可关闭重复接触计算，实际夹持验证在另一个启用接触的物理模型中完成。两者关节顺序／状态一一核对，不能把渲染模型的设置误读为本版没有夹持求解。

FCL缓存加速只复用网格加速结构，不改几何或阈值。27个有效夹持对照、4个无效反例与原检查结果一致，胶垫距离差为0；4个插座碰撞／无碰撞例也与原逐mesh检查一致。

边界试采：9种代表性夹持均通过，62个候选中61个有效；模块零位、横向−3mm／竖向−3mm、孔口前0.5mm的组合因模块与插座mesh相交而拒绝。试采目录独立于正式数据。

## 标注与存储

保存实际物理状态求得的`T_camera_from_module`、`T_camera_from_socket`、`T_tcp_from_module`及真实达到的三变量／插座关系，另保留请求参数，不能拿请求值替代真值。

每张有效图保存RGB、可见实例掩码（0背景含夹爪，1刚性模块，2插座装配）、边界框和像素数、物理状态、接触与网格检查。掩码不包含绿色活动拉环。后处理可由位姿生成尖端、夹持区参考点和孔中心的相机／像素坐标；这些几何参考点可能被遮挡或位于几何内部，不自动标为“可见关键点”。

完整表面标签使用已认可的方案一共享模板（模块37895点、插座204820点）＋每图实际变换，不重复保存几万份相同几何。模板清单固定在`/data/omi_runtime/runs/contact_wrist_surface_20261123_r01/network_templates/manifest.json`。

## 数据划分和后续训练限制

整个夹持格点通过稳定hash分到train／val／test，同一格点所有插座配置和外观变化保持同一集合。名义零位属于train，因此密集插座网格在训练组；该划分衡量限定范围内夹持配置与配对视图插值，不能据此宣称完整插座域或真机泛化。

密集插座层会使零位模块出现次数较多，后续训练应按夹持格点与覆盖层平衡采样，不能直接按所有图片等权采样后误以为几何分布均匀。所有视图是独立静态状态，sample_id不是连续时间；不得直接当作时序轨迹训练。

当前仅随机化光源、强度、桌面／地面颜色和拉环角，仍有同源背景及同一相机／资产域的局限。真实数据、插入遮挡、不同相机校准与接触动力学后续单独扩充。

## 复现入口

1. `scripts/perception/build_grid_perception_plan.py --output <新目录>`生成范围、格点和候选目录。
2. 使用`omi_mesh_audit`环境运行`generate_grid_perception.py --plan <新目录> --output <新目录>/shards/shard_i --shards 8 --shard-id i`，i为0～7。推荐`MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1`。名义零位视图均匀分配到8进程，但仍保持同一训练分组。
3. 所有分片完成后运行`audit_grid_perception.py --run <新目录>`，检查分区完整性、图像／mask、每张实际状态重放和接触重算。
4. 运行`filter_grid_three_variable.py --run <新目录>`导出严格主集，父集保留。
5. 用`verify_grid_render_replay.py --run <新目录>`抽样重渲染核对掩码与光度差异。
6. 运行`render_grid_perception.py --run <新目录>`生成范围、拒绝区域、图片与点云查看器。

`data/shards`链接原分片，迁移须同时恢复`shards/`和共享模板。不要覆盖现有运行。采样标注完成不等于网络精度已经提高，后续需要另开预训练与独立评估。

## 完成结果与质量分层

16490个候选全部有结果：16251张物理有效图像，239个未收录组合。其中203个因模块与插座mesh相交拒绝；另外36个来自6个模块格点，当前闭合过程结束后偏离请求格点或三变量约束。这6个状态仍能稳定夹住，但没有达到请求姿态，不应解释为实物上绝对夹不住。

细网格检查发现部分物理有效样本仍存在小幅横向偏移／非俯仰转动。为贴合用户的三变量任务，另外导出`data_strict/`作为推荐主数据集，原`data/`保留不改。主集要求：前后／上下误差各≤0.1mm，俯仰误差≤0.25°，左右偏离中心≤0.02mm，非俯仰转动≤0.05°。这些是本版工作质量阈值，非真机计量或网络精度。

| 数据层 | 图像数 | 用途 |
| --- | ---: | --- |
| 严格三变量主数据集 | 14549 | 后续预训练／评估推荐入口 |
| 物理有效但偏离严格约束的辅助样本 | 1702 | 保留用于诊断与后续对照，不默认混入主集 |
| 未产生有效视图 | 239 | 保存请求参数、拒绝原因和可用失败状态 |

主集按夹持格点分组：训练12463张、验证987张、测试1099张，覆盖1926个不同模块格点。1989个候选格点中，63个没有严格主集图像；部分其他格点的插座视图也被筛掉。`coverage_by_grasp.json`和`coverage.csv`明确记录这些缺口，不能把“全部检查”说成“全部有效覆盖”。物理有效父集覆盖1983个格点，父集图像划分为13959／1110／1182。

`sampling_pools.json`按覆盖层保存主集索引。后续推荐交替使用模块主网格与插座密集网格监督，并按模块格点平衡采样；插座零位密集层的重复模块零位标签不应被当作均匀模块监督。该采样器训练尚未执行。

## 验证与标注样例

16251张物理有效图全部核查RGB／mask哈希、掩码像素数／边界框、分组、实际物理状态重放及双侧接触重算；位姿矩阵最大差0，重算最小单侧法向力约1.601N。请求插座关系与实际达成关系最大平移分量差约0.03249mm、旋转差约0.00306°；这是采集达成偏差，不是网络预测误差。模块表面至孔口参考平面的最小间距约0.50008mm，未进入插槽。

独立抽取14个代表状态重新渲染，可见实例掩码全部逐像素一致。RGB并非逐字节一致：最大单图平均像素通道差约0.000745（0～255量程），最大变化像素比例约0.0722%。保留最初严格RGB逐像素断言失败日志，以及后续完整光度差异报告；没有把微小光度差异写成完全一致，也没有改变数据几何验收。源资产哈希再次核对未变。

样例`annotation_example_5964/`已实际导出RGB、可见掩码、标注JSON、完整点云NPZ及两个PLY，点数模块37895、插座204820，坐标为腕部光学相机系、单位米；不是网络预测。导出脚本：

```bash
MUJOCO_GL=egl /data/omi_runtime/envs/omi_mesh_audit/bin/python   scripts/perception/export_grid_annotation.py   --run /data/omi_runtime/runs/grid_perception_20261123_v1   --sample-id 5964 --output /data/omi_runtime/runs/grid_annotation_NEW
```

总运行目录约1.5～1.7GB，共享模板通过`network_templates/`链接引用。`data/`和`data_strict/`均链接`shards/`，迁移必须一起保留。主数据集入口是`data_strict/records.jsonl`；不要把物理父集或试采目录误作严格主集。

可视化窗口提供四个覆盖层、参数滑条、实际图像／可见mask、完整或重点点云、明确拒绝状态、边界照片和有效区域图。黄色状态为辅助样本，红色状态不显示其他图片冒充该格点。结果不是插入成功率或新网络成绩。

恢复：`python3 -m http.server 8895 --bind 127.0.0.1 --directory /data/omi_runtime/runs/grid_perception_20261123_v1`。完整运行清单在`manifests/grid_perception_data_20261123_v1.json`。
