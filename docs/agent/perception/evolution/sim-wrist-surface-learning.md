# 腕部RGB到完整点云：首轮仿真监督学习

用户要求用现有仿真生成腕部视频，利用特权位姿对应mesh，变化抓取位置／俯仰及机械臂姿态，实际训练图片到点云网络并查看效果。本轮已完成采集、标签核对、训练、独立配置测试、视频及可旋转点云展示。

实验：`/data/omi_runtime/runs/sim_wrist_surface_20261122_r01/`。结果窗口：`http://127.0.0.1:8892`。[操作与复现](../../../../tutorials/sim_wrist_surface_learning.md)。原8890未训练原型、8891表征窗口、8876人工调整及既有真实标注均保留。

显示修正：用户看不到绿色，原因是旧图像先画绿色、后画密集橙色，3D也使用同样叠画顺序。新默认视频改为左绿真值／右橙预测，同帧同尺度；逐帧图像与3D也支持独立显示，叠加图用绿圈／橙点。新产物在`results/color_compare_v2/`，旧视频保留。训练报告、预测数组和检查点哈希完全不变，只修显示。

## 数据与仿真

### 接触适用性复核（用户要求对照GC-r01）

核对[GC-r01接触修订](../../simulation/evolution/wrist-contact-closure.md)、r01的`data/config.json`和冻结生成器后确认：现有3072帧（训练2304、验证384、测试384）仍使用WG-r10＋OM-r08。生成器显式设置`mjDSBL_CONTACT`，`set_grasp`直接改模块body位置／旋转，段内保持相对腕部变换固定，仅执行运动学更新与渲染。没有让自由模块经双指闭合达到接触平衡，也没有逐配置双侧接触／力／滑移筛选。

因此当前数据是**未验证夹持可行性的运动学视觉基线**。渲染位姿标签可以自洽，但接触空隙、穿入或不稳定夹持的发生率尚未逐帧审计，不能据此宣称全部姿态物理可行，也不能无证据称全部样本都有穿模。约1.92mm测试误差仅在该旧生成分布上成立。

GC-r01为WG-r15＋OM-r08上的独立自由模块夹持场景；其5例保持／移动／释放检查不属于上述训练数据，插槽碰撞在该单测中也关闭。文档中的0.046／0.602mm间隙是WVA-01参考装配测量，不是WG-r10训练集的逐帧测量。旧训练模块俯仰±4°等扰动也不能直接继承GC-r01小范围案例的通过结论（两者坐标定义需转换）。

下一批数据应在独立运行中接入修订后的夹持机制：改变自由模块初态→闭合双指→验证两侧实际接触力及运动稳定性→从实际物理状态读取相机／模块／插座变换→渲染与记录。保留失败案例及失败原因；稳定夹持训练样本按检查筛选。若扩展到插入遮挡，还需独立启用并验证插槽接触。当前尚未据此生成新数据或重新训练。


本轮使用MuJoCo 3.15完整机械臂场景，来源为已装配WG-r10＋OM-r08的机器人场景。使用[固定视觉资产合同](../../simulation/evolution/wrist-assets-handoff.md)，没有按目录mtime挑选资产，也没有替换源文件。原156个工具／模块文件前后哈希一致。

每帧使用机械臂FK更新实际场景，再按腕部相机变换渲染五个有效方形面，重投影为OpenCV鱼眼。采样面672×672，最终960×540，内参按像素中心规则从1920×1080缩放，D不变。第六个面在这套视野中无输出像素，不渲染。

这是**运动学场景渲染**，未执行接触夹持／插入动力学：模块在每段视频内固定于夹爪，段间改变抓取配置；机械臂在段内沿平滑路径改变位置与姿态。图像内包含夹爪遮挡，但没有主动生成插入后的深遮挡数据。仿真K/D按给定候选使用，与真机的精确绑定仍未认证。

| 变化 | 配置 |
| --- | --- |
| 模块在夹爪内的横向位置 | 模块X方向约±0.5mm |
| 前后拿取位置 | 模块长轴Y方向约±4mm |
| 上下位置 | 模块Z方向约±1mm |
| 尖端俯仰 | 绕模块X约±4°，绕抓取参考点`(0,25,0)mm`变化 |
| 另外两轴小角度 | 约±1.5° |
| 机械臂 | 通过IK改变TCP位置／姿态，七个活动关节确实变化；使用正的接近间隙 |
| 外观扰动 | 光源位置／强度、桌面与地面颜色；绿色挂件角度独立在−35～0°变化 |

绿色挂件保留为图像中的干扰变化，不进入目标点云；没有额外黑白marker，调试site／关节轴不进入训练图像。工具碰撞／质量未标定，不能将这些视频当作真实抓取或接触成功验收。

## 真值与目标几何

保存每帧`T_camera_from_module`、`T_camera_from_socket`、相机与TCP世界变换、关节位置和图像哈希。标签取自同一渲染状态下的MuJoCo实际body／camera变换，不是请求的IK目标或人工拟合。

- 3072图哈希和分辨率检查通过。
- 9个跨划分样本独立重算FK，与保存标签最大矩阵差0。
- 129个渲染部件的编译网格世界顶点与原作者坐标比对，最大差约1.08e−8m。
- OM-r08的15个目标主体部件与模板使用的V4-r05几何逐顶点一致；绿色挂件与假设内部阴影块不作为目标点。

`training_label_valid=true`仅指**仿真模型内的已知位姿监督**；`real_world_ground_truth=false`。没有把原287组真实数据的候选标签改为有效。

## 训练实现

沿用完整表面网络与分层模板：模块22528点、插座43008点。动态输入只有RGB；人工ROI、关节位置、相机世界位姿和点云初值不进入推理。相机内参／mesh模板是固定配置。

共享ResNet-18骨干从官方ImageNet权重初始化，新增双目标注意力／局部裁剪／位姿头进行微调。BN运行统计固定。平均位姿与注意力初始中心仅由训练集计算；同时保留“始终输出训练集平均位姿”作为基线。

- AdamW，骨干学习率3e−5，其余可学习头3e−4，余弦调度；batch16。
- 25轮，共3600次优化器更新；按验证集选择第19轮权重（该检查点2736次更新）。
- 损失包括归一化平移、旋转矩阵、分层表面Huber和注意力中心监督。每对象每步用256全局＋512关键面＋256棱边代表点计算几何损失，推理仍展开全部点。
- 图像仅作亮度／对比度增强，不进行破坏相机坐标的未标定空间裁剪或翻转。
- 可见性头未训练，存在头未校准，不使用其分数作为置信度。
- 初期4次更新的小样本流程检查单独保留在`train_smoke_r02/`，不作为最终成绩。

训练本身约369秒；数据生成约590秒，均为本机本次记录，不是跨硬件速度承诺。没有修改OMI的SAC／BC策略，也没有发送真机运动指令。

## 独立配置测试

检查点选择只使用验证集。最终在32个未参与训练的配置／384帧上：

| 指标 | 固定训练均值基线 | 网络均值 | 网络P90 |
| --- | ---: | ---: | ---: |
| 模块平移误差 mm | 2.331 | 1.164 | 2.405 |
| 模块旋转误差 ° | 2.144 | 1.045 | 1.763 |
| 插座平移误差 mm | 22.759 | 1.372 | 2.771 |
| 插座旋转误差 ° | 3.160 | 0.266 | 0.458 |
| 尖端在插座坐标系中的误差 mm | 21.423 | 1.922 | 3.397 |

尖端使用模块轴线参考点`(0,−35.0931697,0)mm`，由两对象的相对SE(3)计算。X／Y／Z绝对误差均值约0.505／1.481／0.735mm，轴向误差占比较大。最大单帧相对误差约8.16mm，不能以均值掩盖。

将保存的确定性预测与随机打乱的测试标签重新配对，尖端误差均值升至29.463mm。这是配对打乱负对照，支持网络利用了图像变化；不是额外真机泛化验证。

从最佳检查点实际执行三张测试图的完整`forward(images)`，输出22528×3和43008×3；与评估用位姿展开一致。单张／batch推理存在浮点归约差异：最大表面点差约0.0039mm，远小于上述误差。最初过严的逐元素矩阵阈值失败日志保留，最终按平移、旋转、表面点的几何单位检查。

## 可视化与局限

视频包含前四个测试配置、误差居中的配置和平均误差最大的配置；静态对照还包含最大误差单帧。所有384帧可逐条查看和旋转预测／真值点云。绿色是真值，橙色是预测；点投影可能显示遮挡部分，不能用投影外观替代定量测试。

当前结果证明了**固定仿真资产与随机范围内的图像→位姿→完整点云学习**。尚未验证真实图像、物体缺失、超出扰动范围、插入后深遮挡或真实插接准确率。约1.9mm平均相对误差仍不能支持亚毫米插接精度承诺；下一步优先改善轴向误差、扩大遮挡／姿态覆盖并做真实数据验证。

本轮插座固定在世界坐标，主要通过机械臂运动改变其相对相机的位姿。网络可能利用桌面／其他机器人部件等背景线索；配对打乱只能证明图像有作用，不能证明只依赖目标自身特征。下一轮应独立移动插座、改变背景并设置更强遮挡，以检验这类依赖。

关键入口：`data/label_audit.json`、`train/report.json`、`train/best.pt`、`full_forward_check/report.json`、`results/heldout_predictions.mp4`及`inference_example/`。
