# 图像到完整表面点云

后续已有[仿真监督训练版本](sim-wrist-surface-learning.md)：25轮、3600次更新和独立配置测试已完成，8892展示当前训练结果。下文记录保留的无权重原型阶段；8890仍是历史模板／原型页面。

2026-11-22用户明确希望以图片为输入、完整物体表面点云为输出，表达网络对场景的估计。已实现已知模板约束的图像网络原型：[完整设计](../../../design/image-to-complete-surface.md) · [操作与复现](../../../../tutorials/image_to_complete_surface.md)。

光模块默认2048点，插座默认8192点；固定嵌套point_id，包含全表面和关键区采样、法向、材质色、部件及三角形来源。模板点被验证在源三角形上，源mesh未修改；插座含下支架，模块不含绿色挂件。

网络动态输入只有RGB图像；共享ResNet-18全图特征与自动局部裁剪，两对象独立中心／深度／连续6D旋转头，将完整模板变换到相机坐标，另输出存在／可见性logits。不输入人工位姿或点云，不预测缩放／自由形变。

实际用1920×1080腕部图像运行，输出`2048×3`与`8192×3`；旋转和模板刚体变换自一致。真实图像与灰图产生不同数值，表明输入进入了计算图，但不证明学习能力或精度。使用合成标签进行反向检查，84个参数张量梯度有限；12,426,396参数。首个CUDA前向约0.74秒，仅是冷启动运行记录，不能外推稳态帧率。4项单元测试及7项浏览器显示检查通过。

**网络与骨干均未训练，优化器步数0。** 图像预处理在首张手工屏蔽附加标贴区域，尚非批量自动忽略；当前数据缺少可靠6D标签，默认拒绝把候选标注当有效监督。完整形状由既有mesh提供，隐藏面的输出是先验推测。未进行真实精度、可见性置信度或操作成功率验收，也未改OMI策略／硬件控制。

产物：`/data/omi_runtime/runs/image_to_complete_surface_20261122/`。原型窗口端口8890与人工调节端口8876独立；数据在`templates_v2/`与`prototype/`，报告、图片、来源和源码快照随运行目录保存。
