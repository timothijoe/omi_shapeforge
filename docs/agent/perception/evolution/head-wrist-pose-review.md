同日后续：按用户反馈把共用的坐标切换栏改为**两个视图下方各六轴的独立调节栏**。左侧仅修改头部点云中的模型位姿，右侧仅修改腕部像素投影位姿，原始点云不动。两组各有粗细范围、归中、初始化、恢复载入值，光模块和插座都适用。外参修改只改变候选，必须另点“应用外参”才替换腕部两对象的位姿；沿用原存储字段，无需迁移已保存标注。

同日再次修正初始化与可辨识显示：旧ROI形状拟合会出现错面／错轴和局部滑移，用户认为难以精调。新增有序四角点击＋局部双目深度初始化，绕开局部PCA的方向歧义；当前首条由助手选择可见几何角点，生成可载入建议，不是自动识别。RGB显示改为目标邻域密集采样，附加选区辅助色／邻域过滤／点大小；点云位置本身不变。

## 实现

- `scripts/perception/pose_review_server.py`：本机127.0.0.1 HTTP服务、287样本索引、按需点云、位姿／历史保存和来源登记。
- `pose_review_geometry.py`：米制SE(3)、IR→RGB、鱼眼投影、选区点云多方向配准、手工3D／2D对应精修。
- `pose_review.html`：无外部CDN依赖的WebGL点云及Canvas原图线框；两组常显六轴滑条／数值框、目标切换、独立恢复、撤销、逐条保存、点选结构对应及外参候选。另有折叠的高级外参调节。
- 兄弟仓库`FoundationStereo/scripts/infer_pose_review_sample.py`：单样本32迭代双向推理、一致性过滤、米制点云和来源报告；不改变原数据。

使用V4-r05主体及黑色端件；绿色挂件和假设内部阴影块不参与。插座读取SIM-r06固定视觉网格，下支架仅可选显示且不参与拟合；不导入动态等效触点。模型不缩放。

## 坐标与可辨识性

每对象保存`T_head_from_model`和`T_wrist_from_model`，头部采用左IR光学坐标。显示头RGB时读取每条样本的列主序工厂外参。用同对象的两个候选可以构造`T_wrist_from_head = T_wrist_from_model @ inverse(T_head_from_model)`，再用另一对象检查一致性。由同一对象构造的零误差不算独立标定。腕部／头部相对位置随机械臂运动变化，外参候选按样本保存。

手工像素精修只优化用户选定的对应，不使用marker或全图边缘吸附。至少4个不同且不共线的3D点；局部搜索20mm／20°各轴界限，触边、退化点集或相机后方解会拒绝。部分遮挡／错误对应仍可产生数值上合理的错误解，结果始终为候选，`training_label_valid=false`。
