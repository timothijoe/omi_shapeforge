# 感知总章程

## 目标和职责

将双目深度、已有模型与观测配准组织成可追溯、可评估的项目流程。主项目维护输入、调用、结果和评估边界；算法实现由相应后端仓库维护。

## 长期约束

记录原始输入来源、代码状态、模型版本和单位；保留失败和近似多解，不以低残差替代独立真值。已知 ROI 的条件配准、全场景检测、完整重建和实物位姿精度分别验收。模型尺度变化及相机／模型变换必须显式记录。

保持运行环境与源码边界清晰，不把第三方代码和未获许可的资源打入主仓库。原始观测与旧输出保留，新实验独立存放。

## 完成标准

入口与依赖可定位，实际执行有报告，失败有记录，检查方法与使用的先验可说明；共享版本需能从提交与资源清单恢复，而不只保留一个差异哈希。

当前实现和证据见[双目与后端](evolution/stereo-and-backends.md)、[已确认目标配准](evolution/confirmed-registration.md)和[数据与回放](evolution/data-and-replay.md)。
