# 002：默认采用完整稀疏背景与关键面加密展示

状态：accepted。日期：2026-11-25。依据：用户认可分层点云查看器，要求记录docs、按此格式制作视频，并将其用于之后大部分点云。

同日配色复审：用户进一步认可A冷银灰电影，登记r10版本，模块普通色RGB(216,221,228)纳入`layered-points-v2-cool-silver`默认策略；橙绿重点和分层／同点径约定不变。旧v1和旧影片保留。

同日腕部叠加追加：用户指定RGB图像只画橙绿重点，其余原图保留；v3据此区分腕部重点叠加和独立完整三维点云。原普通点仍用于几何与可见性，采样数据不删改；r11已交付，用户确认显示规则并要求归档，已认可r10仍保留。

后续多数新点云展示采用完整物体背景＋任务关键面加密，层间同一点径，普通面中性灰，指定重点橙／绿。交互检查可分层切换并放大；独立交付必须有能直接看见的预览及不依赖WebGL的兼容路径。视频保留实际源时间轴、相机与姿态来源，不用绘图效果替代几何密度。

此决定约束展示约定，不强制所有资产共用同一毫米间距或ROI，也不重写冻结训练模板、点预算、损失函数、检查点及历史结果。明确指定的旧方案仍可恢复。

具体字段、采样／显示区别、已认可查看器、视频接入及来源边界以[能力纪传体](../evolution/pointcloud-presentation.md)和[可执行样式登记](../../../../configs/pointcloud_presentation.json)为准。
