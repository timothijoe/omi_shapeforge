# 001：独立后端进程与环境

状态：accepted。形成于 2026-11-19，本篇于 2026-11-20依据现有实现补录。

两个算法仓库存在同名模块、不同历史依赖及机器编译扩展。主项目承担调度与证据管理，通过配置的 Python 解释器启动子进程，各后端维护自己的环境和源码。

因此控制层保持标准库依赖，命令以参数列表执行，报告与日志保留在外部新目录；依赖版本由各后端状态和运行记录追溯。不会把整个算法源码、权重或虚拟环境复制进主项目。

代价是跨后端调用目前以文件／进程为边界，不能当作统一内存内流水线；后端工作树尚未提交时，共享恢复能力仍不完整。[当前实现](../evolution/stereo-and-backends.md)维护这些限制。
