# 2026-11-21：停用附加 marker，改为模块自身结构线

用户明确黑白标贴是额外添加的，不使用它；希望利用端部壳体、台阶、缺口等固有结构。此前等待确认标贴是否移动的问题已取消，相关纹理/标贴绑定路线不再是当前主线。历史试验保留，不作为新结构算法的观测。

## 已完成

新增 `scripts/perception/structural_edge_pose.py` 和 `run_structural_edge_trial.py`，在给定抓取视角/粗位姿先验的原始 1920×1080 鱼眼图上进行：

- 在计算梯度前填平标贴区域，并排除其周边梯度带；其区域仅用于排除，不提供位姿对应。
- 提取杆身左右边、金属头部左右边、黑色端壳下沿五组结构线。
- 由原 V3 网格提取对应三维直线，并数值检查采样点确实位于相应 mesh 表面；包含刚性黑色端部件 `007.npz`，不包含绿色挂件。
- 用鱼眼反投影得到图像直线的相机射线平面，与三维结构线进行刚体位姿拟合，保持模型尺寸与面向先验。
- 黑壳中部的二维台阶线可以提取，但其准确 CAD 对应尚未确认，没有用于求姿态。头部台阶和插接端缺口在当前画面中不能可靠辨认时不使用，也不把插座遮挡边界当作缺口。

这不是任意位置、任意视角的全图识别。搜索区域针对已有腕部抓取视角显式给定；初始位姿仍是粗搜索先验，不是外部真值。

## 实际结果与限制

61 个采样帧全部得到五组结构线和数值有效的位姿候选。平均直线拟合残差约 1.01 像素等效量，它是角度域线残差乘焦距，不是物理位姿精度，也不是识别成功率。

在首/中/末三帧分别把忽略区域替换为黑色、白色和随机噪声，共 9 个反事实检查；在相同粗位姿和搜索先验下，提取的结构线与位姿候选不变。当前求解没有用 marker 身份、角点、纹理或它在模型上的三维坐标。

遮住杆身后只剩头部两侧和黑壳下沿。未经保护的试算虽然线残差极小，相比未遮挡解仍跳变约 12.3 mm／22.4°；该失败已保留。当前对这组不充分的可见约束输出 `partial_structure_requires_prior`，不给出新的六维观测。完全遮挡时无有效结构，不输出位姿。这个四线下限是当前试验的保守保护，不是“三条线在数学上绝对不能求位姿”的一般结论。

**当前完成的是 marker-free 结构特征提取和位姿候选生成，尚未完成遮挡下可靠精确六维位姿、相对插入深度或到位判断。** 台阶/缺口三维对应、局部模型几何精度、真实遮挡和独立精度验证仍待完成。
