## 实际方法和产物

使用已知橙色夹爪视角先验定位主体，在 ROI 中根据灰度转折／GrabCut 提取前端和近端头部特征，按 V3 几何代理角点建立四点对应，再执行 SQPnP 与鱼眼重投影优化。每张图独立求解，没有使用 EEF 角度作为模块相机位姿，也没有用时间平滑掩盖跳变。

使用真实 V3 全部网格做带深度遮挡的自身可见性绘制；黄色为主体、青色为模型拉臂。外部夹爪／插座的遮挡没有三维建模。四点规则可能在被遮挡时误把插座当作模块端点；低拟合误差不能证明对应正确。当前规则开发时看过 19c7887c／8083942d 的部分图，其他回合是诊断对照而非带真值的独立精度测试。

## 当前结论

**现有原型不能认为能稳定、准确地识别这些回合中的所有姿态。** 抽查发现主体粗对齐、被插座误导的对应、遮挡导致拒绝及可见范围变化引起的错误姿态。19c7887c 的 tick 88 约只有 0.50 ROI 像素的拟合角点误差，mesh 却明显延伸到插座上，是不能使用“低重投影误差＝准确识别”的直接例子。拉臂投影也普遍与真实拉手有偏差，需核对该部分模型。

记录的 EEF pitch 属于 base_link；相机和模块通常共同运动，不能当成模块相对相机的俯仰真值。“估计轴向夹角”只是在相机系中由候选旋转矩阵算出的模块长轴与光轴锐角，也不是独立真值。这批数据主要覆盖该腕部设置下的接近、遮挡和有限夹持变化，不能证明任意视角的泛化能力。

数值验证包括原发布器坐标采样一致性、ROI↔原图往返、合成鱼眼 PnP 回算，以及渲染缓存修改与原首帧逐像素一致。这些只验证实现，不提供真实 6D 准确率。

后续优先改进稳定可见的头部特征、遮挡判断和真实 mesh 约束；另外建立独立的图像对应／位姿验证集，再评估不同物体相对相机俯仰。当前结果用于诊断查看，不作为已验证的机器人控制或 RL 真值输入。原 episode、内参及 V3 网格未修改，未连接 ROS、执行硬件或训练模型。
