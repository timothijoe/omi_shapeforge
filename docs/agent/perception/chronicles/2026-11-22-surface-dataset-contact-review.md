# 感知数据集接触适用性复核


### 接触适用性复核（用户要求对照GC-r01）

核对[GC-r01接触修订](../../simulation/evolution/wrist-contact-closure.md)、r01的`data/config.json`和冻结生成器后确认：现有3072帧（训练2304、验证384、测试384）仍使用WG-r10＋OM-r08。生成器显式设置`mjDSBL_CONTACT`，`set_grasp`直接改模块body位置／旋转，段内保持相对腕部变换固定，仅执行运动学更新与渲染。没有让自由模块经双指闭合达到接触平衡，也没有逐配置双侧接触／力／滑移筛选。

因此当前数据是**未验证夹持可行性的运动学视觉基线**。渲染位姿标签可以自洽，但接触空隙、穿入或不稳定夹持的发生率尚未逐帧审计，不能据此宣称全部姿态物理可行，也不能无证据称全部样本都有穿模。约1.92mm测试误差仅在该旧生成分布上成立。

GC-r01为WG-r15＋OM-r08上的独立自由模块夹持场景；其5例保持／移动／释放检查不属于上述训练数据，插槽碰撞在该单测中也关闭。文档中的0.046／0.602mm间隙是WVA-01参考装配测量，不是WG-r10训练集的逐帧测量。旧训练模块俯仰±4°等扰动也不能直接继承GC-r01小范围案例的通过结论（两者坐标定义需转换）。

下一批数据应在独立运行中接入修订后的夹持机制：改变自由模块初态→闭合双指→验证两侧实际接触力及运动稳定性→从实际物理状态读取相机／模块／插座变换→渲染与记录。保留失败案例及失败原因；稳定夹持训练样本按检查筛选。若扩展到插入遮挡，还需独立启用并验证插槽接触。当前尚未据此生成新数据或重新训练。
