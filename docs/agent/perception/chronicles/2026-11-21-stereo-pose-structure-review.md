# 2026-11-21：用户否定贴合质量后的局部结构复核

用户指出双目点云＋像素精修的位姿仍不符合预期。本轮没有把上一轮的 IoU 提升当作验收通过；重新检查局部结构对应，确认存在未被整体指标排除的错误朝向。

## 核查方法

上一轮的像素项仅为主体 mask，点云项为最近 mesh 表面距离，没有把头部台阶、插接端和附着标贴的固定对应纳入约束。点云训练点又主要来自可见表面，因此可以出现表面距离小、轮廓重合高、局部结构却在另一侧的解。

选取 0270、0360、0450、0885 四个可见同一头部标贴的视角。标记字典解码未成功，本轮使用人工粗标的白色标贴外边界四角，不假定标记实际尺寸。将 0360 帧的四角射线与该区域双目点云平面相交，再按已有位姿转换到模型坐标，作为跨帧固定局部特征。0360 是参考定义，不计入验证。

该方法只是跨帧结构一致性诊断：人工标注有数像素误差，参考帧位姿和深度也不是外部真值；偏差不能唯一分摊给位姿、双目深度或标定。

## 发现的明确问题

| 样本 | 上一轮轮廓 IoU | 固定局部特征重投影 RMSE |
| --- | ---: | ---: |
| 0270 | 0.948 | 约 4.1 px |
| 0450 | 0.881 | 约 7.2 px |
| 0885 | 0.886 | 约 74.8 px |

0885 将同一标贴投到了物体另一侧，属于明显结构对应错误，不能称为正确的位姿。它此前不在“候选分数接近”的四帧名单内，说明仅看分数间隔也未能识别该失败。

另检查局部双目支持：0885 人工标贴区域没有可用的所选双目点；0270 的标签区域三维平面与参考帧在模型系中的一致性较差。这里可能包含视角遮挡、RGB/IR 可见性差异、深度或标定偏差，不将它们一概解释为位姿误差。

## 两个诊断试验

保留模型尺寸、原始数据和上一轮结果，只在新目录测试。

1. **自动扩大候选**：从旧联合解及其绕长轴翻面解出发，仍只用轮廓＋点云，不用人工特征优化。0885 局部特征偏差从 74.8 降至约 3.5 px，IoU 0.886→0.938，检查点 P90 0.486→0.384 mm；但 0450 被翻错，特征偏差 7.2→64.4 px，IoU 反而 0.881→0.920，检查点 P90 0.362→1.797 mm。0450 会触发原有深度回退诊断，因此该候选不应采用。这个试验说明扩大候选本身不能可靠解决结构匹配。
2. **增加人工局部对应**：把上述固定标贴角点对应加入优化，属于诊断辅助，不能包装成自动识别结果。0885 选择翻面分支，局部特征偏差约 3.2 px、IoU 0.935、检查点 P90 0.575 mm；0450 特征偏差约 2.6 px、IoU 0.901、检查点 P90 0.955 mm。像素改善与三维残差之间仍有冲突，不能宣称精度已达标。

因此，上一轮结果保持为实验候选，**用户未验收，局部结构检查未通过**。后续应先建立少量可核对的结构点及正反面参考，明确区分位姿错误、模型细节差异和深度／可见性问题，再扩大自动评估。不要继续仅用全局 IoU 排名宣布成功。
