# 2026-11-21：排除夹爪边缘混入模块结构线

用户指出右侧蓝色点落到了夹爪边缘。原检测器只依据固定搜索区域、边缘强度和直线程度选点，没有建立模块/夹爪的归属检查，因此不能将那组点直接视为模块边缘。

## 改动

- 对 marker 屏蔽后的图像运行 SAM2，将金属模块、刚性黑色端部、左右夹爪分别分割。首帧使用明确的前景/负点提示，随后传播到 61 个采样帧；不是无提示全图检测。
- 新结构检测默认要求相同视频、相同原帧索引的归属 mask。竖边需要模块向内一侧的前景支持，黑壳下沿需要黑色端部支持；夹爪边缘邻域和绿色挂件邻域排除。
- 不能确认归属或有效点/跨度不足时输出 `not_observed`，不以更强的背景边缘补齐。
- 位姿求解器不再接受没有经过归属检查的旧边缘记录，防止漏接过滤后静默回到原错误流程。

分割不是物理真值。模块和夹爪接触处可能归属不清，当前采取不使用这些不确定点的方式，而不是声称所有被剔除点都已确认为夹爪内部。

## 实际核查

首帧和末帧的旧 `head_right` 各有 35 个候选点，均未通过新的模块归属检查。余下支持不足以形成可靠直线，该组在全部 61 帧都不再参与位姿拟合。原本潜在五组结构中，当前采用杆身左右、头部左侧、黑色端壳下沿四组。

重跑 61 帧并保留旧结果；没有修改 mesh、重新启用标贴或用手工挪动蓝点来改变结果。候选位姿仍不等于精确位姿，减少错误约束后的低残差不能作为新精度结论。

验证包括：所有接受点均不在夹爪排除邻域内；在固定归属 mask 下，对夹爪内部加入强条纹不会改变接受的模块结构点；没有 mask 时拒绝检测/拟合；9 个 marker 图案替换检查仍通过。反事实检查验证过滤逻辑，不证明神经分割对任意新场景都正确。
