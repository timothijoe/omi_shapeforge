# 开发约定

## 开发位置与职责

主项目开发目录固定为 `/home/linux/omi_folder/omi_shapeforge`。

跨算法的数据处理、相机与模型配置、点云配准、结果评估和可视化功能在本仓库开发。FoundationStereo 网络和 BundleSDF 跟踪、重建实现分别在同级的两个自有 GitHub 仓库中维护。通过配置指定源码位置，保留各自的 Git 历史。

目前使用轻量主环境调度两个独立 GPU 环境。后端以独立 Python 进程启动，避免两套代码中的同名模块及依赖相互干扰。当前调用的是已验证样例脚本；后续逐步增加面向真实数据的接口与流程。

## 版本与结果

开始功能开发时创建分支。主项目与算法库分别提交；实验保留两边的提交号。若尚有本地改动，运行清单记录工作区状态及差异哈希。差异哈希用于识别状态，不能替代提交或补丁保存；正式可共享基线应使用已提交的算法版本。

每个实验使用独立输出目录。原始数据和历史基线保留，新实验结果记录输入来源、参数、提交、日志和指标。`run_manifest.json` 的调度状态和 `report.json` 的算法结果共同作为验证记录。

`manifests/backends.lock.json` 是初始化时的来源快照；当前调度器不强制检出该版本。后续修改算法版本后，应审阅并更新快照，结果清单始终记录实际使用的版本。

## 旧项目迁入

收到 `01_projects_and_results.zip` 后，先将旧工程恢复到独立基线目录，阅读两个项目的原文档并复跑关键结果。之后逐步迁入有效的自定义代码、配置和文档，并补充必要的路径适配。V1/V2 原件、已确认目标和旧错误目标的纠正记录一并保留。

优先接入 V2 几何回放、用户确认区域的配准及旧双目样本复跑。结果记录应区分保存几何的回放、从原始数据重新估计及真实精度验证。
