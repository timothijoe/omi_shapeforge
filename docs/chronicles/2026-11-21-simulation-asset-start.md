# 2026-11-21：独立仿真资产开发前的进展与卡点

用户本轮明确：先从模型和碰撞层面保证插入；**不得修改现有 mesh，要创建新的仿真资产**；资产完成后把整体链路接好。先记录本停点，再继续实现。

## 已完成

- 真实双臂／夹爪 URDF、V3／r04、头部和腕部相机已组成 MuJoCo 场景，双 RGB 十帧观测与 OMI SAC／replay／checkpoint 续训已跑通。
- 初版其他传感器 state／tactile padding，工具抓取变换为假设；接触未进入原预插入任务。
- 规则老师已生成16段预插入成功示范，共824条。来源为 scripted，与 human 分开；视觉BC和混合SAC完成实际更新。
- 原 mesh 已重新导出并检查。模块两条细缝开放、两侧弹片共40个退化面；碰撞派生副本已修复拓扑，不覆盖原Blender。
- U形通道与白框直接凸包会封孔；保留孔形的分解已经验证。

## 当前困扰与未通过项

1. 原完整刚体模型在深度约4.212mm被入口弹片挡住，横向卷边也进入模块侧壁／内部块的占用空间；单铰链让位假设失败。
2. 仅排除入口组件的主体诊断能到51.282mm台阶；此结果不能作为完整插入成功。
3. 原入口组件的自由形状、连接和变形空间尚未标定，不能把弹片穿底板或放宽模块尺寸作为通过方式。
4. 视觉BC在393条训练样本上的Z动作几乎全饱和为−1。轨迹会先靠近再越走越远；动作误差下降不代表闭环成功，SAC之后留出初态仍0/4成功。
5. 原资产尺寸、相机／工具外参和弹性参数未获实物精度认证；工作树保留多个阶段的未提交改动，旧bundle不能覆盖当前工作。
