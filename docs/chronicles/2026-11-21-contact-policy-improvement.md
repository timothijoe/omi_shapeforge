# 2026-11-21：资产说明、视觉策略改善和RL有效性对照

用户先询问独立资产数量与成功案例，要求记录全部进展和问题；随后要求更多尝试，并提出约10回合BC＋20回合带干预RL的流程。另明确额外marker贴纸可以忽略。

## 资产与原有成功案例

现有交付是一套独立装配包SIM-OM001-OS001-r03，内部有模块、插接座和7个被动弹性触点body。模块15个外观件／28个碰撞件，插座113个外观件／335个碰撞件；一份装配blend含501对象，另有491份OBJ。尚未分别封装成模块／插座两个独立资产条目，不是只做了一个物体。原mesh不改，r01／r02候选保留。

局部接触插入退出、机械臂规则循环3/3和规则示范10/10的证据仍有效，见[资产说明](../agent/simulation/evolution/contact-simulation-asset.md)与[先前复核](2026-11-21-simulation-status-review.md)。它们不等于视觉策略成功率。

## 本轮实际实验

1. 查清旧短试跑仅6个BC训练回合、4个无在线接管回合和22次Critic更新，不能与用户提到的10＋20比较。
2. 新采10个训练示范（1749条），验证另留2回合（350条）。固定资产、碰撞及几何成功条件，比较同初始权重、同数据、同3000更新数的普通BC和旋转权重10的BC。
3. 普通BC无接管验证0/2，旋转加权BC验证2/2；这是首次获得本轮自主视觉插入成功。
4. 审查奖励并另设势函数奖励／γ=0.995的独立合同。旧成功轨迹虽为负回报，但高于三个固定失败动作策略，不能把负回报本身当作奖励错误的证明。
5. 第一轮实际跑完20个带规则接管RL回合，19/20接管训练成功；1000预热＋4462在线对应更新，共5462次Critic、2231次Actor更新。与初始BC比较并做等数据额外BC控制。
6. 核对原HIL部署方式，另跑20回合有界探索＋旋转模仿约束组合，从完全相同的预热checkpoint开始。它训练20/20成功，自主测试却失败，未采用。

| 无接管评估 | 第一批4个测试初态 | 第二批4个新确认初态 |
| --- | --- | --- |
| 加权BC基线 | 3/4 | 4/4 |
| 第一轮20回合RL | 4/4 | 4/4 |
| 有界探索＋旋转约束RL | 0/4 | 未追加 |
| 等保留数据／Actor步数的额外BC | 0/4 | 未追加 |

两个不同集合合计 **BC 7/8、第一轮RL 8/8**，评估时没有规则接管。结果说明有改善可能，并已获得真实仿真中的学习策略成功案例；不再只有规则老师成功。

## 能确认与仍不能确认的事

- 可以确认训练实现真的更新了网络、采用了正确的实际执行动作，并在本轮限定测试中取得成功。
- 不能把接管成功当自主成功：第一轮后期探索方差升高、接管占比很高；第二轮接管训练全成功但独立测试0/4。
- 不能说RL必然优于BC。合计差距只有1个成功例，测试很小；额外BC对照并非同序训练，第二轮同时改了两个因素，贡献尚未完全分离。
- 新实验仍为固定相机／资产、每关节±0.0005rad小范围初态，state／tactile padding；不等价于原真机HIL的完整观测和任务条件。
- 姿态偏差、接触卡滞、模拟力峰值、图像增广敏感性、实物标定、真实夹持与整机自碰撞仍需进一步处理。
- 模块与插座的独立子资产封装仍待整理。额外marker贴纸按可忽略附件处理；本轮仿真不依赖该贴纸。
