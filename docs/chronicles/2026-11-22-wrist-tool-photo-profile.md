# 2026-11-22：照片驱动的夹爪轮廓纠正

根据用户新俯视照片，另建WG-r07双峰衬垫轮廓修正版。修正较宽指臂、银色指尖和黑垫比例，黄色衬垫改为两处凸起、中央退让、细窄端部，并重排六角孔和横筋。

初稿沿用27 mm厚度造成参考模块相交；侧视双目复核约11–12 mm，修正为12 mm后无网格相交。49件网格和导出验证通过；27件基体／相机及相机GLB不变，102个旧文件哈希保持。名义黑垫间隙18.4 mm、模块表面余量约0.15 mm，仍未验证真实接触抓取。
