# 开发入口

1. 阅读[当前总览](current.md)和[能力总表](capabilities.md)，先确认要修改哪项真实能力。
2. 按[环境教程](../tutorials/environment_setup.md)检查主环境，运行主 CLI 的 `--help` 与 `doctor`。
3. 修改感知接口前读[感知总章程](agent/perception/charter.md)，修改资产或场景前读[仿真总章程](agent/simulation/charter.md)。
4. 数据格式和资源位置以[接口索引](agent/interfaces/README.md)为准。
5. 只运行与修改有关的检查。文档整理核对链接、help、证据和差异即可，不为刷新日期重跑昂贵实验。

操作步骤统一放在[教程总目录](../tutorials/README.md)；代码边界与分支约定见[项目架构](design/project-architecture.md)。
