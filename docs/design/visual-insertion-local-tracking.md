2026-11-21 开发更新：已实现[模块候选特征与鱼眼跟踪原型](../agent/perception/evolution/mesh-feature-tracking.md)，包括参考锚定、遮挡/丢失/重现状态和逐帧输出。当前三维绑定存在初值相容性问题，默认仅保留二维观测及明确的深度/旋转先验；实验六维更新未验收，插座相对定位也未完成。下文为目标设计，不应把所有环节视为已实现。

## 用户明确的目标

目标是光模块操作过程中的准确局部几何，尤其是部分插入、观测不完整时，利用 mesh、视觉特征和已有姿态先验持续估计**模块相对插口**的关系，服务对准、插入进度和后续结果判断。正反面、哪面朝上/朝前可以作为输入先验，绿色挂件不参与刚体定位。

此前完整物体扫描和单帧轮廓贴合只验证了初始化/局部优化的一部分，不代表已经支持遮挡插入。当前精确视觉位姿仍未验收。

## 模型、特征与位姿的分工

| 输入 | 提供的约束 | 本轮状态 |
| --- | --- | --- |
| V3 与插接座 mesh | 插接端、台阶、入口平面和轴线的固定几何关系 | 已有资产；局部尺寸尚非独立计量真值 |
| 正反面/上下/前后与粗位置先验 | 限定姿态分支和局部搜索范围 | 用户允许；应作为输入，避免重复搜索翻面 |
| 实物视觉特征 | 更新连续位置和旋转，检查滑移、漂移 | 已有参考特征跟踪；物理三维绑定与准确六维更新未验收 |
| 时序与夹持关系 | 遮挡时预测运动、稳定状态估计 | 原型已有参考锚定与预测/丢失状态；真实夹持标定和滑移估计未验收 |
| 两端位姿 | 计算模块相对插口的局部交互关系 | 新增纯几何换算函数，合成检查通过 |

特征需要绑定到模型坐标中的实际部位，或明确绑定到一个参考表面/图像模板。优先采用外露金属头部的稳定纹理、头部台阶、刚性壳体边缘、插座刚性框架和可确认的入口结构。扫描时临时贴的纸质标记不能自动假设也存在于操作画面；每个实物实例/外观版本需有相应参考。

反光高光不是固定物理特征；绿色挂件、接触中会变形的弹片也不宜作为刚体位姿锚点。特征与 mesh 的绑定本身如果来自不准的参考位姿，后续跟踪再稳定也会继承绝对偏差，必须单独核对初始绑定。

## 两个任务坐标系

沿用现有 V3/r04 合同，而不是新增模型尺寸：

- 模块插接端坐标系 `tip`：原点为窄段轴线在名义最前端 Y 平面的虚拟中心；不是实际表面接触点。模块原坐标 Y≈−35.093 mm、X=Z=0。
- 插座入口坐标系 `mouth`：现有金属口沿参考，插座 body 中 `[-0.5,1.85,0.7] mm`。X 横向、+Y 向外、Z 向上，插入沿 −Y。
- 当前金属通道身份必须明确，不可把另一开放仓或屏幕上的“左/右孔”自动当成同一目标。

若两者位姿已经在同一相机、同一时刻：

```text
T_socket_module = inverse(T_camera_socket) × T_camera_module
T_mouth_tip = inverse(T_socket_mouth) × T_socket_module × T_module_tip
```

由此得到横向偏差 X、高度偏差 Z、轴向插入深度 `−Y`、轴线夹角及完整相对旋转。隐藏插接端的位置由 mesh 上的固定几何变换推算；它不是被相机直接看见的新测量。单独估计模块而不估计插口，不能回答是否对准或插到什么程度。

`scripts/perception/interaction_geometry.py` 已实现以上纯几何换算，输入单位显式为米，检查刚性矩阵。输出包含相对变换、偏差、轴向深度及名义台阶轴线点；不输出“已机械到位/电气连接成功”。相同相机/时间是调用方需要保证的前提。

合成检查覆盖入口外 −5 mm、入口 0 mm、内部 20 mm、名义台阶位置，以及任意共同相机变换不改变相对结果、横向/高度偏移、绕插入轴旋转与轴线倾斜的区别、拒绝缩放矩阵。**合成深度 20 mm 等只检查坐标计算，不证明现有完整碰撞模型能插到那里。**

## 部分插入时的观测策略

1. 在可见性充分时初始化两端位姿与实际特征绑定。双目点云用于度量粗位置，视觉结构点用于局部细化。
2. 持续跟踪仍外露的刚性头部、局部纹理和插座周围固定结构。腕部相机与夹爪共同运动时，模块相对腕部可能变化很小；应同时观察插座相对腕部的变化，不能把模块图像稳定误当成没有插入。
3. 对每个特征区分可见、被遮挡、不确定。插座挡住模块产生的边界不是模块端部，不能拿它去压缩完整 mesh 投影。
4. 使用插座/夹爪的遮挡模型或图像分割、深度证据，约束当前实际可见的模型部分。遮挡判断不能仅由当前错误位姿自我解释，否则可以通过随意忽略不匹配区域伪造好分数。
5. 结合前帧与已标定夹持变换作预测；通过外露特征检查模块是否滑移。特征不足时降低可观测方向的置信程度，保留“预测为主/丢失”状态，不能把沿用旧姿态包装成新识别。

定位状态与插接阶段是两套独立信息。离线原型已实现 `initializing / observed_update / prior_assisted_update / prediction_only / lost`，其中六维更新仍为实验模式，尚未接入在线系统。相对几何需要两端可信位姿，不能仅凭特征跟踪状态推断插入成功。

## 操作指标与结果判断

主要评估插接端位置、入口位置、相对轴线角度、插入深度及其不确定性；整物体 IoU 和点云残差只是辅助。姿态误差会通过模块长度放大到插接端，所以不能只报告模型中心的平移误差。

视觉可以为“对准、进入、偏斜、接近台阶”提供证据。机械到位、卡住或电气接通应结合适合任务的实际运动、触觉/力、保持或电气反馈判据。插入成功率要有独立任务结果标签，不能用视觉估计器自己的高置信度给自己作真值。

mesh＋位姿可以确定模型中的交互几何，但实物精度受两端位姿、视觉特征绑定、局部 mesh 和标定误差共同影响。当前 r04 孔宽是检查候选，完整弹片接触尚未通过插入验收；这些限制不会因视觉姿态稳定而消失。

## 后续测试范围

- 仿真遮挡序列：固定真值姿态，逐步遮挡插接端，检查估计是否错误移动/收缩；再加入真实姿态变化、夹持滑移和插座移动。这可验证实现，不代表实物精度。
- 实际 episode：按接近、可见区减少、遮挡、退出/重现分组，检查漂移、重定位和局部结构一致性。已有 9 回合、1682 张腕部 ROI 可用于失败分析；128×128 的数据不能充当高精度真值。
- 原分辨率实际采集：保留腕部 RGB、同步元数据、机器人反馈及标定；关键时刻采集头部 RGB-D。最终精度和插入成功率需要独立参考及真实任务标签。
