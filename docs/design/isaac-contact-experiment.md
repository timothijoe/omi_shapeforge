# Isaac Sim 与 MuJoCo 同源插接实验方案

2026-11-22。用户授权建立与当前MuJoCo对应的Isaac实验。实现与实际结果见[能力记录](../agent/simulation/evolution/isaac-contact.md)。本方案不承诺跨引擎动力学完全一致。

## 冻结基线

第一阶段引用`measured_v4_sim_20261121/robot_scene`与SIM-OM001-OS001-r06：V4-r05几何、18.8×8.8 mm插槽、156个模块凸碰撞件、335个插槽凸碰撞件、7个被动滑动触点。完整双臂URDF沿用已导入MuJoCo的求值结果；固定夹持和关闭机器人自碰撞的假设保持。

最新WG-r08是独立投影对齐候选，尚未在该接触任务验证。第二阶段才将新工具、模块r07材质和鱼眼投影同时接入两引擎，并建立新实验身份；不把它们混入第一阶段。

## 对照约定

- 长度米，Z向上；记录模块、插槽、TCP、两相机的变换方向。
- 每100 ms执行一次6D世界系TCP增量；每轴平移上限1 mm/√3、旋转1°/√3。
- 初始物理步长0.2 ms，完成0.1 ms敏感性试验。PhysX求解器、接触偏移、凸包烘焙及驱动参数独立记录。
- 头部与腕部RGB各128×128，10帧因果历史；state/tactile仍为padding。真值仅用于老师、奖励、评估与诊断。
- 插入需台阶深度误差<0.15 mm、横向误差<0.35 mm、姿态误差<0.01 rad、有头部台阶接触并持续3个控制时刻。数值侵入和触点到底间隙单独限制。接触力采用相同单位，但两引擎接触点数量和积分方式需注明。
- 退出必须从已到位物理状态继续。偏心±1 mm、偏航±2°、锁死触点应受阻。
- 初态使用明确的关节数组及安装变换；只写相同seed不足以保证不同环境初态相同。

## 实施与门槛

| 阶段 | 交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| I0 | 冻结传递包、USD场景、运动学与网格核对 | 原件哈希不变，单位/变换/关节一致 |
| I1 | 局部插入退出、阻挡反例、半步长 | 正常与反例符合任务定义；检查PhysX实际烘焙后的形状 |
| I2 | 完整机器人规则循环与双相机 | 多初态通过；无状态瞬移；相机实际输出且随末端运动 |
| I3 | 接入omi_proj环境适配器 | reset/step/终止/历史/动作来源合同验证，单次更新与重载 |
| I4 | 10回合BC＋20回合规则接管RL | 留出评估关闭接管；对照BC；报告成功、接管、步数及失败 |
| I5 | 引擎及新视觉对照 | 同几何分别训练，再单列跨引擎迁移；扩大初态与训练种子 |

第一版完成范围为I0–I2。I3–I5保留为后续实验，不用场景加载或规则成功代替网络训练。

## 工程结构与差异

`export_isaac_contact.py`在MuJoCo环境读取已求值模型，冻结几何数组、惯量、关节、相机和来源哈希。Isaac进程只读取数据包，不调用MuJoCo步进。`isaac_contact_scene.py`生成USD；`isaac_contact_kinematics.py`提供独立正向运动学；`isaac_contact_runtime.py`执行PhysX与任务测量；`run_isaac_contact.py`输出运行证据。

固定链接合并惯量和碰撞，但保留命名坐标架。铰链/滑动关节支持当前标量合同；不宣称为通用MJCF转换器。夹指mimic未迁移，第一版保持固定开度。材质暂用RGBA近似，未迁移纹理。MuJoCo的solref/solimp没有逐值等价的PhysX参数。

Isaac采用独立解释器与外部补充依赖目录；不修改系统驱动、不覆盖旧环境或旧资产。所有试验使用新目录。首次测试优先限定单环境；RTX和训练共享显存，是否并行须在实际测量后决定。

## 本轮实施结果

I0–I2的限定规则实验已完成：PGS局部7项和机械臂3初态循环通过，实际RTX双相机与视频已保存。seed7采样接触力超过学习评估的10 N停止阈值，因此进入I3/I4前先处理近台阶接触力与门控，不能把规则通过当作可直接训练的验收。见[实际记录](../agent/simulation/evolution/isaac-contact.md)。
